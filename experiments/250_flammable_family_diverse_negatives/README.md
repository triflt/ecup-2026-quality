# 250: Family-diverse hard negatives for Qwen3.5

## Гипотеза

В каждом внешнем обучающем наборе для категории «Легковоспламеняющиеся» прежний отбор 1600 отрицательных строк содержит только 1253–1299 независимых семейств. В сложной половине выборки 206–237 из 800 мест заняты повторными строками тех же семейств; одно семейство может занять до 20 мест. Отбор одного представителя на семейство должен дать модели больше различных отрицательных причин и уменьшить ложные срабатывания на новых товарных семьях.

## Единственный изменяемый фактор

Архитектура, prompt, первое изображение, seed, optimizer, число обновлений, положительные примеры и соотношение «сложные/случайные» остаются такими же, как у принятого родительского варианта. Меняется только единица отбора 1600 отрицательных flammable-примеров: вместо строк выбираются 800 наиболее сложных семейств и 800 случайных семейств, по одной строке из каждого.

Эксперимент запускается после решения по `241`. Поскольку семейный баланс положительных примеров не прошёл заранее заданный критерий устойчивости, положительные примеры возвращены к исходному построчному повторению. Единственным новым фактором остаётся семейный отбор отрицательных примеров.

## Проверка

- данные: `competition_train_v1`;
- протокол: `nested_grouped_v1`;
- неизменные folds: `validation/grouped_text_v1`;
- первичное сравнение: новый seed `42` в паре со строго неизменным seed `31415` против родительского двухseedового варианта; отдельно, без подбора по Public, проверяется перенос только flammable-ветки в зафиксированный ансамбль `190`;
- критерий: не меньше `+0.001` Macro F1, не меньше `4/5` побед и падение любой категории не больше `0.005`.

Машиночитаемый результат находится в `results/metrics.json`. Все адаптеры сохраняются локально; разрешённый удалённый путь — только `private://competition-artifacts/`.

Предварительный аудит сохранён в `analysis/sampling_audit.json` и `analysis/sampling_by_fold.csv`. Он воспроизводит полный порядок использования генератора случайных чисел родительского обучения. Новый отбор повышает среднюю дистанцию от порога на `0.0327`, то есть немного ослабляет концентрацию на почти одинаковых пограничных строках; это заранее принятая плата за 299–328 дополнительных независимых семейств.

## Решение до обучения

Эксперимент не запущен. После Public-ничьей `280` и появления маршрутизации `400`
родитель `230` перестал быть подходящей точкой сравнения. Исполняемый цикл также
содержал подтверждённую ошибку: вопреки карточке он включал отклонённый фактор
положительного баланса `241`. Ошибка исправлена, аудит пересчитан, но ветка
заменена экспериментом `410`, который проверяет тот же фактор поверх точного
рецепта адаптера `260` и применяет результат только к flammable-категории.
