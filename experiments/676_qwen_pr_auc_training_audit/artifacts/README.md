# Local artifacts

Содержимое этого каталога не публикуется. Для каждого файла указываются источник, SHA-256, размер и команда построения в `results/metrics.json`.

Эксперимент не копирует крупные adapters или predictions. Их SHA-256 фиксируются в результате;
он воспроизводим только при совпадении checksum.
