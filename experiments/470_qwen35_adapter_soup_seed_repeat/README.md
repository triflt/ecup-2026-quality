# 470: независимый seed-повтор смеси Qwen3.5-адаптеров

## Гипотеза

Эксперимент `430` показал небольшой, но согласованный по выбранной доле прирост от
точной смеси исходного Qwen3.5-адаптера и специалиста `260`. Проверяется, является
ли выигрыш свойством направления в пространстве весов, а не особенностью seed 42.

Новый специалист обучается по неизменному рецепту `260` с `seed=31415`. Для folds
0 и 3 он сравнивается со смесью `0,50/0,50` с исходным адаптером `230` того же seed.
Категория БАД, базовая модель, Qwen3-VL, веса ансамбля и production priors не
меняются. Смесь остаётся одним rank-32 адаптером и требует один проход Qwen3.5.

## Замороженный экран

- folds 0 и 3 выбраны заранее: именно на них `430` менял решения;
- alpha специалиста фиксирована на `0,50`, сетки и повторного выбора нет;
- seed фиксирован на `31415`;
- пороги для folds перенесены из nested-выбора `430`, не подбираются на новых
  прогнозах;
- рецепт обучения полностью совпадает с `260`.

Экран подтверждён, только если смесь выигрывает на обоих folds, средняя разница
Macro F1 положительна, false negatives для flammable и safety-union не растут и
исправлений больше, чем ухудшений. В противном случае полный цикл и пакет отправки
не создаются.

## Precedent

Метод следует общей практике model soups: усреднение совместимых решений в одной
области весов может повысить устойчивость без дополнительного прохода. Здесь
проверяется более узкий причинный механизм — линейная интерполяция совместимых
LoRA-изменений, причём независимый seed отделяет устойчивый эффект от случайной
траектории обучения.

## Состояние

Эксперимент завершён и отклонён. Обе задачи успешно завершились, их архивы
прошли проверку CRC, безопасного состава, контрольных сумм, порядка строк,
fold и seed.

На folds 0 и 3 средняя разница Macro F1 равна `+0,001001`, однако знак не
устойчив: fold 0 дал `−0,000158`, fold 3 — `+0,004058`. Смесь изменила восемь
решений: четыре исправила и четыре ухудшила. Flammable false negatives стало на
один меньше, включая один пример safety-union, но два заранее заданных критерия
не выполнены: улучшение есть не на обоих folds, а исправлений не больше
ухудшений. Полный пятираздельный цикл и архив отправки не создаются.
