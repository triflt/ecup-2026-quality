# Эксперимент 685 — ранговая дистилляция в Qwen3.5-4B

Статус: `TERMINAL_REJECT_AT_OUTER0`. Public-отправок: `0`.

## Гипотеза

Проверялось, сможет ли небольшой deployable-классификатор перенять порядок
примеров от сильного офлайн-учителя. Контроль обучался только с обычной
бинарной функцией потерь. Кандидат использовал тот же набор пар, порядок,
инициализацию, модель, LoRA, оптимизатор и число шагов, но смешивал обычную и
ранговую функции потерь с равными весами.

## Результат outer fold 0

- Average Precision: `0,8681151 -> 0,8864609` (`+0,0183458`);
- F1 легковоспламеняющихся: `0,8253968 -> 0,8064516` (`-0,0189452`);
- изменение Macro F1 при неизменном БАД: `-0,0094726`;
- FN: `8 -> 9`, FP: `3 -> 3`;
- исправлено/ухудшено: `1/2`.

Оба обученных компонента прошли проверку происхождения и точного паритета;
единственным научным отличием был вес ранговой функции потерь `0` против
`0,5`. Все 943 проверочные строки были связаны с неизменяемым реестром данных.
Обучение не читало проверочные метки, Public не использовался.

Вывод: ранговый сигнал перенёсся, но итоговая граница решения ухудшилась.
Эксперимент отклонён до следующих разбиений, полного обучения, упаковки и
Public. Следующая отдельная гипотеза должна сохранить полный вес обычной
бинарной функции потерь и добавить ограниченный ранговый регуляризатор.
Поскольку fold 0 уже повлиял на формулировку, следующая слепая проверка должна
начинаться с fold 3.

Точные метрики и контрольные суммы компактного терминального отчёта находятся
в [results/outer0_terminal.json](results/outer0_terminal.json).
