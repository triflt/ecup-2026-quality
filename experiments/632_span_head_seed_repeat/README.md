# 632: независимое повторение exact-span модели 623

Статус: **полная независимая проверка пройдена; разрешена интеграция в 140**.

Меняется только seed обучения `42 → 31415`. Модель, данные, внешний
semantic-family split, селектор обучающих строк, prompt, LoRA, дополнительные
головы, веса функций потерь и пороги полностью совпадают с 623.

Цель — проверить, является ли прирост 623 следствием задачи поиска точного
доказательства, а не удачной инициализации. Экран использует заранее выбранные
folds 0 и 3. Положительный экран разрешает folds 1/2/4, но не заменяет полную
проверку. Sealed holdout и Public не используются.

Precedent: независимые траектории обучения являются стандартной проверкой
variance learned components; локальная необходимость подтверждена провалом
переноса seed-эффектов в экспериментах 230 и 470.

Две независимые однокарточные задачи для folds 0 и 3 завершились успешно.
Проверены ZIP, внутренние контрольные суммы, отсутствие меток validation и
sealed-строк. На неизменных donor-only порогах оба fold улучшились:

- fold 0: `+0.099125` Macro F1;
- fold 3: `+0.016605` Macro F1;
- средняя delta: `+0.057865`;
- исправлено 99 решений, ухудшено 52;
- flammable false negatives: `14 → 3`.

Все заранее заданные screen-gates пройдены, поэтому folds 1/2/4 были обучены тем
же рецептом и seed. Полная проверка дала Macro F1 `0,910876` против `0,887605`
у исходной Qwen3.5, delta `+0,023270` и победы на `4/5` folds. БАД улучшился на
`+0,010793`, легковоспламеняющиеся — на `+0,035747`; исправлено 244 решения
против 130 ухудшений, flammable FN снизились `30 → 14`, grouped bootstrap
`P(Δ>0)=0,9659`. Все frozen gates пройдены.

Это принимает **компонентную** гипотезу, но ещё не делает 632 сабмитом. Следующий
однофакторный эксперимент 635 проверяет замену, фиксированное среднее и
evidence-gated применение внутри полной архитектуры 140 без изменения её
остальных весов и порогов.
