# 241: Изолированный баланс положительных flammable-семейств

## Зачем понадобилась новая версия

В эксперименте `240` семейное распределение положительных примеров использовало общий генератор случайных чисел. Из-за этого последующая случайная половина отрицательной корзины тоже изменилась: в каждом внешнем разбиении заменились 587–625 из 1 600 отрицательных строк. Результат `240` проверяет полезность всего набора данных, но не отделяет вклад семейного баланса.

Версия `241` использует отдельный генератор только для распределения положительных flammable-примеров. Положительные БАД, отрицательные БАД и все отрицательные flammable-строки полностью совпадают с исходным seed `42`. Архитектура, prompt, изображения, число предъявлений, порядок перемешивания, оптимизатор и разбиения не меняются.

Локальный аудит `analysis/isolation_audit.json` сравнил мультимножества обучающих индексов на всех пяти разбиениях. Для каждой корзины вне целевых положительных flammable-примеров получено точное совпадение.

## Как работает новая выборка

В родительском обучении каждая положительная строка легковоспламеняющейся категории показывается модели пять раз. Поэтому семейство с несколькими почти одинаковыми карточками получает непропорционально много предъявлений, а одиночное семейство — только пять.

Новая версия сначала объединяет положительные строки по нормализованным названию и описанию. Общее число предъявлений не меняется, но распределяется между семействами максимально равномерно. Внутри каждого семейства конкретная строка выбирается случайно с возвращением. Модель, архитектура, prompt, число обновлений и применение после обучения остаются прежними.

## Схема проверки и итогового обучения

Обучаются пять проверочных адаптеров нового seed `42`: каждый видит четыре групповые части и предсказывает пятую. Их непересекающиеся прогнозы образуют единый внеобучающий прогноз. Для каждого внешнего разбиения веса и пороги выбираются только по четырём обучающим частям.

Мы сравниваем рецепт семейного баланса с рецептом `230`, а не выбираем лучший адаптер отдельного разбиения. Новый seed `42` в каждой части заменяет исходный seed `42` и усредняется с неизменным seed `31415`. Шестой адаптер обучается на всех данных заранее для экономии времени, но не участвует в оценке. Если критерии пройдены, именно этот полный адаптер заменит seed `42` в архиве; пять проверочных адаптеров в отправку не попадут.

## Отличие от лучшего Public-решения `190`

Public-решение использует один Qwen3.5 seed `42` с построчным повторением редкого положительного класса. `241` наследует двухseedовую схему `230` и меняет только данные для нового seed `42`: положительные легковоспламеняющиеся примеры распределяются по семействам равномерно. Все остальные модели, правила товарных семейств и порядок применения остаются теми же. Следовательно, возможное улучшение можно связать именно с покрытием редкого положительного класса, а не с новой архитектурой применения.

## Основное сравнение

Новый seed `42` заменяет исходный seed `42` в среднем вероятностей с неизменным seed `31415`. Исходный уровень — Macro F1 `0.9192367221`. Гипотеза принимается при приросте не меньше `0.001`, победе хотя бы на четырёх из пяти разбиений и падении любой категории не больше `0.005`.

Все контрольные файлы и адаптеры хранятся локально. Если понадобится удалённое хранение, разрешён только `s3://private-artifact-store/private-prefix/`.

## Результат

Задание `redacted-job` успешно завершило пять внешних обучений и одно итоговое обучение на всех данных. Архив проверен командой `unzip -t`; SHA-256 исходного private compute platform-архива — `76af902c7afa4f387a1ba7d4c90424b3ec01a100535afaaa6330c92e7b7cedf2`.

Новый seed `42` был объединён с неизменным seed `31415` средним вероятностей и оценён тем же `nested_grouped_v1`, что и `230`:

- BAD F1: `0.9534841954` (`+0.0016086894`);
- flammable F1: `0.8967254408` (`+0.0101275027`);
- Macro F1: `0.9251048181` (`+0.0058680960` к `230`);
- победы по внешним разбиениям: `3/5`;
- grouped bootstrap: `P(delta > 0) = 0.8403`, 95%-й интервал `[-0.00564; 0.01839]`.

Средняя метрика выросла, но заранее заданное требование минимум четырёх побед из пяти не выполнено. Гипотеза отклонена. Дополнительно Public-результат родительского `230` (`0.8639458233`) оказался ниже `190` (`0.8919244237`), поэтому локальное улучшение относительно `230` само по себе больше не является достаточным основанием для отправки.

Полный адаптер сохранён для анализа и возможной консервативной проверки с фиксированными весами `190`, но не считается кандидатом на лидерборд.
