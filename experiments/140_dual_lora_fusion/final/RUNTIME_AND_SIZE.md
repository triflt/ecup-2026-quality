# Офлайн-запуск, время и размер

Это требования к исполнимости решения, а не метрики качества модели.

## Офлайн-запуск

Во время проверки у контейнера нет доступа в интернет. Базовые модели
загружаются из предоставленного соревнованием `SHARED_MODELS_PATH`, а LoRA и
классификаторы — из архива решения. Рабочий скрипт ничего не скачивает. Он ищет
изображения только в каталоге `images/` рядом с входным CSV и передаёт локальные
URI вида `file://` во встроенную библиотеку обработки изображений. Библиотека
поддерживает сетевые URL, но решение 140 их не создаёт.

## Время работы

Официальные лимиты на одной H100 80 GB: 3 минуты для Check, 20 минут для Public
и 40 минут для Private. Frozen E2E smoke финальной системы обработал 600 строк
за `341 s`; explanation-stage занял `89.76 s`. Все 600 строк прошли схему, а
verdict совпал с solution140 в 600/600 случаях. Расчётное время составляет
`15.16 min` для Public и `35.99 min` для Private. Запас укладывается в лимиты,
но эти значения должны быть подтверждены фактическим запуском нового архива.

## Размер

ZIP-архив решения должен занимать не более 5 GB, сжатый Docker-образ — не более
15 GB. Финальный `exp714-solution140-reasoner-4b-b192-final.zip` занимает
55 770 475 байт. В него входят три LoRA-адаптера, обученные классификаторы и
исходный код; базовые модели предоставляет среда соревнования. SHA-256 архива:
`a0695a55a85ca835d18f23e3700ee3eccc9ba03b9d490653719f474c38861bce`.
Размер Docker-образа ещё нужно записать после фактической проверки.
