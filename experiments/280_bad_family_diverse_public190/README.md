# 280: Разнообразные положительные семейства БАД в Public-архитектуре 190

## Гипотеза

Построчный отбор положительных БАД тратит 240–269 из 1 500 мест на повторяющиеся товарные семейства. Замена только Qwen3.5-адаптера seed `42` на адаптер `260`, обученный на разных положительных семействах, должна улучшить перенос на новые товары без дополнительного времени применения.

## Единственный изменяемый фактор

Архив является точной копией подтверждённого Public-решения `190`, кроме Qwen3.5-адаптера. Сохранены robust text/image base, Qwen3-VL-адаптер, веса и пороги объединения, семейные правила, индекс редких пятисловных последовательностей и один проход Qwen3.5.

Поэтому время применения соответствует `190`: около `10,17` минуты на Public и `24,15` минуты на Private, с запасом к ограничениям 20 и 40 минут.

## Проверка

Протокол `locked_190_nested_v1` фиксирует веса Public-архитектуры до обучения кандидата. Для каждого внешнего разбиения подбирается только порог по остальным четырём разбиениям. Новый адаптер получил Macro F1 `0,930613` против `0,923409`, прирост `+0,007204` и победил на четырёх из пяти разбиений. BAD снизился на `0,002064`, что меньше защитного ограничения `0,005`; flammable вырос на `0,016473`.

Групповой bootstrap даёт `P(прирост > 0) = 0,8275`; 95%-й интервал `[-0,00807; 0,02322]` пересекает ноль из-за малого числа положительных flammable-семейств. При пяти доступных попытках этот кандидат выбран для одной информативной Public-проверки.

## Связь с сильными решениями

Rakuten SIGIR 2020 показал пользу независимых text/image-моделей и decision-level fusion для шумной товарной классификации. Class-Balanced Loss (CVPR 2019) формализует уменьшение новой информации от повторяющихся примеров. Здесь обучающий бюджет Qwen3.5 перераспределён с повторов строк на независимые товарные семейства без изменения архитектуры применения.

## Сборка

```bash
python3 experiments/280_bad_family_diverse_public190/build_submission.py \
  --output experiments/280_bad_family_diverse_public190/artifacts/quality-public190-badfam-v280.zip
```

В архив входит полный адаптер `260`, обученный на всех размеченных данных. Пять адаптеров внешних разбиений используются только для оценки и в архив не входят.

## Решение

Public Macro F1 равен `0,8919244237`, то есть совпал с результатом `190` до
отображаемой точности. Гипотеза об онлайн-улучшении опровергнута: `260` не заменяет
исходный Qwen3.5-адаптер в рабочем решении, а чемпионом остаётся `190`.

Равный итоговый F1 не доказывает, что построчные прогнозы совпали: исправления и
ухудшения могли взаимно компенсироваться. Результат используется только как
проверка заранее зафиксированной замены; веса и пороги по нему не подбираются.
