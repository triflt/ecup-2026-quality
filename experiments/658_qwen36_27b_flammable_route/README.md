# 658: Qwen3.6-27B только для легковоспламеняющихся

Статус: **отклонён на замороженном экране: не пройден только gate отношения
исправлений к новым ошибкам**.

Эксперимент 654 показал причинно различный эффект одной class-only 27B:
flammable F1 вырос, а БАД и общее отношение исправлений ухудшились. Текущий
production precedent 400 уже показал, что известную категорию можно использовать
для выбора специализированного адаптера без нового порога и без второго прохода.

658 оставляет predictions 641 для БАД и берёт predictions 654 только для
легковоспламеняющихся. Порог обеих моделей остаётся нулевым, веса отсутствуют.
Сначала рассчитываются уже обученные folds 0/3. Остальные folds 27B разрешены
только если оба Macro delta положительны, средняя не меньше `+0,0015`, ни одна
категория не падает сильнее `−0,002`, corrected/regressed не ниже `1,5`, а
flammable false negatives не растут.

Положительный экран не делает маршрут production-кандидатом. Нужны folds
1/2/4, минимум `4/5` побед, те же guardrails, затем однофакторная замена только
flammable Qwen-сигнала внутри неизменного ансамбля 140.

## Результат

- средний прирост Macro F1 на folds 0/3: `+0,0221125`;
- прирост на fold 0: `+0,0177632`, на fold 3: `+0,0264618`;
- БАД не менялся; F1 легковоспламеняющихся вырос на `+0,0440257`;
- false negatives легковоспламеняющихся: `10 → 3`;
- исправлено 18 строк, испорчено 13, отношение `1,3846 < 1,5`.

Несмотря на большой прирост F1, заранее заданный gate не ослабляется. Остальные
folds 27B не запускаются. Сигнал передаётся в новый, заранее фиксируемый
эксперимент 659 с равным усреднением уверенности 4B и 27B.
