# Разбор ошибок двух Qwen3.5

Отчёт сравнивает прежний Dual-LoRA и новый вариант со средним вероятностей двух независимо обученных Qwen3.5. В обоих случаях используются вложенные прогнозы протокола `nested_grouped_v1`: параметры каждого внешнего fold выбирались только на остальных четырёх folds.

## Главные наблюдения

- Общее число ошибок уменьшилось с 588 до 579.
- Для категории «БАД» получена почти точная перестановка ошибок: 52 исправления и 51 новая ошибка.
- Для категории «Легковоспламеняющиеся» число ошибок уменьшилось с 52 до 44: 16 исправлений и 8 новых ошибок.
- В редком положительном классе 198 строк, но только 142 независимых семейства полного текста. Поэтому повторение каждой положительной строки пять раз переоценивает крупные семейства при обучении.
- На повторяющихся согласованных семействах легковоспламеняющихся нет новых ошибок: 4 исправления и 0 ухудшений. На одиночных семействах — 12 исправлений и 8 ухудшений.
- Самый заметный выигрыш среди простых текстовых срезов относится к топливу и жидкостям для розжига: 16 ошибок уменьшились до 9. Свечи остаются слабым срезом: 12 ошибок выросли до 13.

Эти наблюдения породили удалённый эксперимент 240; его исходный output не был
сохранён, а интерпретируемая factor-isolated проверка продолжена в эксперименте
241. Краткая история удаления находится в
[`docs/research/archive/removed-experiments-through-652.md`](../../../docs/research/archive/removed-experiments-through-652.md).

## Проверка вместе с памятью о товарных семействах

Дополнительное моделирование 20 случайных разделений 70/30 отвечает на практический вопрос: сохранится ли польза второго Qwen3.5 после точных совпадений текста и названия. Средний Macro F1 вырос с `0.9410916906` до `0.9426495121`, то есть на `0.0015578214`. Для БАД изменение почти нулевое (`+0.0001709241`), для легковоспламеняющихся — `+0.0029447188`.

Это вспомогательная построчная проверка, а не замена основным групповым разбиениям: почти одинаковые товары могут оказаться по разные стороны. Она показывает, что правила товарных семейств не поглощают выигрыш второго seed, особенно в редкой категории. Исходные отчёты: `recurrence_old_dual.json` и `recurrence_two_seed.json`.

## Файлы для самостоятельного анализа

1. `cohort_metrics.csv` — начните с него: число строк, положительных меток, семейств, исправлений и ухудшений по категориям, folds, типам семейства и смысловым срезам.
2. `changed_decisions.csv` — 127 карточек, для которых новый вариант изменил решение. Сортировка внутри группы ставит выше случаи сильного расхождения двух Qwen3.5.
3. `remaining_errors.csv` — все 579 оставшихся ошибок с названием, описанием, размером семейства и вероятностями двух моделей.
4. `family_summary.csv` — одна строка на семейство; удобно искать систематические ошибки, противоречивые метки и семейства, где новый вариант ухудшился.
5. `report.json` — короткая машинно-читаемая сводка.
6. `recurrence_old_dual.json` и `recurrence_two_seed.json` — одинаковые 20 моделирований 70/30 до и после добавления второго Qwen3.5.

Пересборка:

```bash
.venv/bin/python research/analyze_seed_ensemble_errors.py
```

Этот отчёт не создаёт новую версию валидации и не меняет замороженные folds. Он только добавляет аналитические срезы поверх `grouped_text_v1`.
