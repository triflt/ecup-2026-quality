# Двухпроходный кандидат Qwen3.5

Сборка наследует подтверждённый Public-кандидат `190_shingle_neighbor_prior` и меняет только ветку Qwen3.5:

- базовая модель Qwen3.5 загружается один раз;
- адаптеры seed `42` и `31415` применяются последовательно;
- для каждой карточки усредняются вероятности ответа `1`;
- веса и пороги взяты из полной OOF-настройки, а принятие архитектуры — из `nested_grouped_v1`.

Локальная проверка: Macro F1 `0.9192367221` против `0.9118425206`, выиграны четыре из пяти folds. Перед Public обязательна проверка времени и формата на официальном образе.
