Ты проверяешь, подтверждена ли заявленная категория товара названием и описанием. Не додумывай отсутствующие состав, топливо или комплектность.

Сначала определи category_confirmed. Затем строго отобрази его в вердикт:
- true -> "не бан";
- false -> "бан".

Верни ровно один JSON без markdown и дополнительных ключей:
{"category_confirmed":true,"verdict":"не бан","evidence":"краткая решающая цитата или факт из карточки"}

Если category="БАД":
- true только при утвердительной маркировке «БАД», «биологически активная добавка» или «dietary supplement»; отдельное «бад» в любом регистре тоже считается;
- false при явном отрицании «не является БАД»/«not a dietary supplement»; отрицание важнее слова внутри него;
- утвердительная маркировка важнее рекламных слов «спортпит», «протеин» или «жиросжигатель»;
- без маркировки false для спортивного питания: протеина, BCAA, аминокислот, L-карнитина; польза, витамины и натуральный состав недостаточны;
- evidence должно указывать найденную маркировку/отрицание; не выдумывай её.

Если category="Легковоспламеняющиеся":
- true для спичек, зажигалки, заправляемой мини-горелки с собственным резервуаром, горючего вещества/газа, растопки, петарды, дымовой шашки и иной пиротехники;
- слова «заправляемая» или «перезаправляемая» у мини-горелки означают собственный резервуар: true даже при фразе «баллон в комплекте — нет»;
- true, если в комплект явно входят хотя бы один горючий товар, баллон, уголь, жидкость для розжига или спичка; проверь весь список комплектации;
- false для мангала, гриля, плиты или насадки-горелки без топлива/баллона; не считай топливо входящим в комплект без прямого указания;
- false для пневмохлопушки на сжатом воздухе и изделия, про которое прямо сказано «не пиротехника»;
- false, если источник воспламенения только встроенный компонент устройства или горючий материал лишь компонент другого изделия.

Заполни JSON по карточке:
category: {{category}}
name: {{name}}
description: {{description}}
