# 350: контрфактическая абляция текстовых shortcut для sports-BAD

## Гипотеза

Эксперимент `320` слегка улучшал sports-когорту на всех connected-разбиениях,
но ухудшал широкий medicine/context union. Эксперимент `330` показал, что одного
согласия production-компонентов недостаточно. Нужен новый доступный при инференсе
признак: как меняется strong-text score, если удалить из текста регуляторные или
спортивные фразы.

Это не новый label-head. Для каждого outer fold прежний TF-IDF/LinearSVC рецепт
обучается только на donors и трижды оценивает один товар: исходный текст, текст
без регуляторных spans и текст без sports spans. Разности score отражают
контрфактическую чувствительность модели к shortcut.

## Замороженное правило

Изменения разрешены только для connected-safe `БАД ∩ sports_nutrition`:

- предполагаемый FN: `190=0`, оба LoRA-компонента голосуют за 1, в тексте есть
  явная маркировка БАД, удаление regulatory снижает text score, а удаление sports
  повышает его;
- предполагаемый FP: `190=1`, оба LoRA-компонента голосуют за 0, явной маркировки
  БАД нет, удаление sports снижает text score.

Порог каждого LoRA-компонента оценивается только на donor rows. Regex, знаки
дельт и условия направления фиксируются до подсчёта внешних метрик. Все unsafe,
non-sports и flammable ответы побитово совпадают с `190`.

## Проверка

Сначала считаются исторические connected-safe folds, затем без изменения правила
три `connected_family_repeated_v1` topology. Обязательны component bootstrap,
singleton-sports срез, corrected/regressed отдельно для FN и FP, placebo-абляция
нейтральных marketing spans и donor-only replay production priors.

Для принятия нужны connected-safe Macro `>= +0,003`, `4/5` побед, BAD
`>= +0,006`, sports `>= +0,01`, corrected:regressed `>= 2`, все repeat delta
положительны и их среднее `>= +0,003`, положительный singleton-sports результат,
bootstrap `P >= 0,90`, отсутствие эффекта placebo и положительный результат после
priors. Full refit и пакет запрещены до прохождения всех условий.

## Итог

Гипотеза отклонена:

- connected-safe Macro `−0,000206`, победы `2/5`;
- 44 изменения: 19 исправлений против 25 ухудшений;
- sports F1 `−0,000572`, singleton-sports `−0,003706`;
- repeat delta: `−0,000097 / +0,000052 / −0,000047`;
- bootstrap `P(прирост > 0)=0,271`;
- после production priors разница `−0,000145`.

Median sports-ablation effect на изменённых строках (`0,0653`) действительно
выше neutral-placebo (`0,0330`), поэтому трансформация измеряет задуманный shortcut.
Но сам shortcut не совпадает с соревновательной меткой достаточно точно. Полный
refit и пакет не создаются.
