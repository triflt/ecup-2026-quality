# 659: равное усреднение 4B и 27B для легковоспламеняющихся

Статус: **полная пятифолдовая проверка принята как офлайн-сигнал учителя;
упаковка 27B и отправка на Public запрещены**.

658 подтвердил, что 27B на обоих screen-folds существенно лучше 4B по редкой
категории, но полная замена создаёт слишком много новых ошибок. 659 сохраняет
4B для БАД. Для легковоспламеняющихся он берёт арифметическое среднее исходных
логитов 4B и 27B с фиксированными весами `0,5/0,5`, затем применяет неизменный
нулевой порог.

Ни вес, ни порог не выбираются по folds 0/3. Это минимальная проверка механизма
снижения дисперсии двух независимо обученных моделей одного семейства. Gate
полностью совпадает с 658: положительный прирост обоих folds, средний не меньше
`+0,0015`, падение категории не ниже `−0,002`, corrected/regressed не ниже
`1,5`, false negatives легковоспламеняющихся не растут.

При провале эксперимент закрывался без обучения новых 27B-folds. После успеха
экрана были обучены folds 1/2/4, а итоговый маршрут проверен на всех пяти
разбиениях без настройки весов, порога или состава данных.

## Результат экрана

- средний прирост компонентного Macro F1: `+0,0488115`;
- fold 0: `+0,0647226`, fold 3: `+0,0329004`;
- БАД не изменялся; F1 легковоспламеняющихся: `0,816901 → 0,916667`;
- false negatives легковоспламеняющихся: `10 → 2`;
- исправлено 17 строк, испорчено 3, отношение `5,6667`;
- все заранее записанные gates пройдены без изменения весов или порога.

## Полный результат

- положительный прирост на `5/5` folds;
- средний прирост компонентного Macro F1: `+0,0306689`;
- pooled F1 легковоспламеняющихся: `0,843931 → 0,907514`;
- БАД побайтово сохраняет прогноз 4B и остаётся `0,951562`;
- false negatives легковоспламеняющихся: `24 → 13`;
- исправлено 25 строк, испорчено 3, отношение `8,3333`;
- tie-aware pooled PR-AUC: `0,880379` у 4B, `0,919542` у 27B и `0,932038`
  у их фиксированного среднего. PR-AUC использован только как диагностика.

Все frozen gates пройдены. Результат доказывает, что большая обученная модель
несёт устойчивый дополнительный сигнал для редкого опасного класса. Однако
27B не помещается в допустимый архив и вместе с текущим ансамблем превышает
лимит времени. Поэтому 659 — только офлайн-учитель и научная абляция: её нельзя
упаковывать, отправлять на Public или считать новым production-чемпионом.
Следующий допустимый шаг — перенести этот сигнал в deployable 4B с отдельным
экспериментом и полной frozen CV; обычное объединение OOF-ответов учителя для
обучения запрещено из-за утечки второго уровня.
