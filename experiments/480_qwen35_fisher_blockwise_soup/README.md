# 480: поблочная Fisher-смесь Qwen3.5-адаптеров

## Гипотеза

Глобальная смесь `430` с долей специалиста `0,50` дала небольшой положительный
сигнал, но независимый seed-повтор `470` не подтвердил устойчивость на обоих
разбиениях. Вероятная причина — разные блоки адаптера несут полезную специализацию
и потерю общей полноты в неодинаковой степени, поэтому одна доля для всех блоков
слишком груба.

Для каждого LoRA-блока на train-части оценивается средний квадрат градиента:
исходный адаптер измеряется на широком наборе положительных и трудных отрицательных
примеров, специалист — на flammable positives и близких отрицательных примерах.
После нормировки внутри типов `q/k/v/o` доля специалиста равна
`G_specialist / (G_original + G_specialist)`, ограниченная интервалом `[0,10; 0,90]`.
Эффективные LoRA-изменения объединяются точно в один rank-32 адаптер.

## Замороженный экран

- seed `31415`, folds 0 и 3;
- коэффициент Fisher `lambda=1,0`, без сетки и подбора по holdout;
- одна строка на нормализованное товарное семейство в калибровке;
- для расчёта важности используются только четыре train-fold;
- baseline — глобальная смесь `0,50` из `470` при тех же исходном и
  специализированном адаптерах;
- веса ансамбля `0,15/0,10/0,75` и пороги из `430` не меняются.

Экран проходит, если кандидат улучшает оба fold, средний прирост не меньше
`0,001`, flammable и safety false negatives не растут, исправлений больше
ухудшений, не менее четверти блоков отклоняются от `0,50` хотя бы на `0,10`, а
ранговая корреляция коэффициентов между fold-калибровками не ниже `0,50`.

## Состояние

Протокол подготовлен до получения предсказаний. Запланированы две независимые
однокарточные задачи на folds 0 и 3. Полный цикл и архив отправки до прохождения
экрана запрещены.
