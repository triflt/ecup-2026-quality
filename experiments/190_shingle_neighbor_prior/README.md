# 190: Rare-shingle neighbour prior

## Гипотеза

Rare five-word shingles найдут почти одинаковые BAD cards без exact match.

## Протокол

Dataset: `competition_train_v1`. Основной evaluation protocol: `recurrence_70_30_v1` из `validation/registry.toml`. Frozen grouped folds лежат в `validation/grouped_text_v1/folds.csv`; global OOF и single-fold scores помечаются как диагностические.

## Как работает подтверждённое Public-решение

Эксперимент `190` — текущая точка отсчёта с Public Macro F1 `0.8919244237`. Для каждого товара решение выполняет следующие действия.

1. Текстовый классификатор преобразует название и описание в признаки TF–IDF и выдаёт оценку отдельной линейной моделью для каждой категории.
2. Qwen3-VL-Embedding превращает текст и изображения в один вектор, после чего второй линейный классификатор выдаёт независимую оценку.
3. Ранги двух оценок образуют устойчивую базовую оценку: вес текста равен `0.85` для БАД и `0.65` для легковоспламеняющихся товаров.
4. Два адаптера с дообучением малой части параметров независимо оценивают товар: Qwen3-VL-2B и Qwen3.5-4B seed `42`.
5. Для БАД смешиваются базовая оценка, Qwen3-VL и Qwen3.5 с весами `0.50/0.25/0.25`; для легковоспламеняющихся — `0.15/0.10/0.75`. После порога получается предварительное решение.
6. Поверх него действуют правила товарных семейств. Сначала используются совпадение полного нормализованного текста, затем совпадение названия, затем совпадение после маскирования чисел. Если ни одно правило не сработало, для БАД ищутся близкие карточки по редким последовательностям из пяти слов. Достаточно уверенное семейное правило заменяет решение модели.

Public-отправка содержит модели, обученные на всех доступных размеченных данных. Проверочные модели отдельных разбиений в архив не входят. Результат Public подтверждает весь этот порядок действий одновременно, но не позволяет приписать прирост только последнему правилу по пятисловным последовательностям.

## Как проверялись компоненты

Связанные карточки объединяются в товарные семейства, чтобы одинаковые или почти одинаковые товары не оказались одновременно в обучении и проверке. Модели пяти внешних разбиений дают по одному прогнозу для каждой строки вне своего обучения; эти прогнозы образуют единую внеобучающую оценку. Дополнительные разделения 70/30 проверяют устойчивость семейных правил при повторном появлении похожих товаров. По этим проверкам выбирается рецепт решения, а не одна из пяти моделей. После выбора тот же рецепт обучается на всех данных для отправки.

```bash

python3 experiments/190_shingle_neighbor_prior/run.py --data /path/to/data.csv --images /path/to/images
```

## Результат

Donor-only BAD +0.000853; 20/20 проверок повторяемости выиграны. Полная система получила **0.8919244237 Public Macro F1**. Этот результат подтверждает архитектуру целиком, но сам по себе не измеряет отдельный вклад shingle prior.

Подробные machine-readable результаты находятся в `results/metrics.json` и `reports/experiment-log.csv`.
