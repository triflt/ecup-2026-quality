# 450: смысл сделки для легковоспламеняющихся товаров

## Гипотеза

У решения `400` осталось 36 ошибок в категории легковоспламеняющихся. Все они
находятся вне пересечений связанных товарных семейств; 31 относится к огню,
пиротехнике или розжигу, а в 19 случаях критично понять, входит ли опасный
предмет в продаваемый комплект. Поэтому новый опыт не меняет Qwen3.5, Qwen3-VL,
обучающие метки или категорийную маршрутизацию. Он добавляет дешёвое текстовое
представление, сосредоточенное на смысле сделки.

Представление строится без меток: название повторяется дважды, затем берутся
предложения с заранее зафиксированными словами о комплекте, совместимости,
исключениях, топливе и источниках огня. На этой строке независимо для каждого
внешнего разбиения обучается линейный классификатор. Векторизатор и классификатор
видят только четыре обучающих fold; пятый fold используется один раз для оценки.

## Интеграция

Для БАД решения `400` копируются без изменений. Для легковоспламеняющихся новый
ранг получает одну из заранее заданных долей `0,05/0,10/0,15/0,20`, а прежние
веса `0,15/0,10/0,75` пропорционально уменьшаются. Доля и порог выбираются только
на остальных четырёх fold. При равенстве выбирается меньшая доля.

## Приёмка

Полный nested Macro должен вырасти минимум на `0,003`, flammable F1 — на
`0,006`; нужны `4/5` побед, не менее 1,5 исправления на одно ухудшение, отсутствие
роста false negatives и защитной группы, а также connected bootstrap
`P(delta>0) >= 0,90`. Слова, окно, сетка весов и критерии записаны в
`analysis/selection_manifest.json` до расчёта прогнозов.

## Результат

Эксперимент отклонён без изменения зафиксированных слов и весов:

- Macro `0,924901` против `0,931645` у 400, разница `−0,006744`;
- flammable F1 `0,895141` против `0,908629`, разница `−0,013489`;
- строгих побед `0/5`: три fold упали, два не изменились;
- изменено 7 решений: 1 исправлено, 6 ухудшено;
- flammable false negatives `+4`, safety-union false negatives `+2`;
- connected-safe разница `−0,007048`, bootstrap `P(Δ>0)=0,0158`.

На всех внешних fold donor-выбор предпочёл минимальный разрешённый вес `0,05`,
но даже это давление не перенеслось. Список слов и веса задним числом не
перенастраиваются. Полная модель и архив отправки не создаются.
