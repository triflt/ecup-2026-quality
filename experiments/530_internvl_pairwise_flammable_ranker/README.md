# 530: попарное обучение InternVL для категории «Легковоспламеняющиеся»

## Проверяемая гипотеза

Сильное решение `400` иногда ошибается на товарах, которые похожи по словам и
изображению, но относятся к разным сторонам соревновательной границы. Например,
сам факт, что товар способен гореть, ещё не определяет правильную метку. Поэтому
в этом опыте InternVL учится не давать общий ответ о товаре, а сравнивать
похожие подтверждённые и неподтверждённые товары.

Это независимая модельная ветвь без большого учителя и псевдометок. Меняется
только один компонент решения: на заранее замороженных 909 трудных товарах
категории «Легковоспламеняющиеся» ранг Qwen3-VL заменяется рангом InternVL с тем
же весом `0.10`. Остальные товары, ветвь БАД, веса, пороги и правила решения
`400` остаются неизменными.

## Как зафиксированы обучающие пары

Выбор 909 товаров сделан без меток и полностью взят из опыта `300`. Для каждого
проверочного разбиения пары строятся только из разрешённых строк остальных
четырёх разбиений. Метки проверочного разбиения не участвуют ни в выборе пар, ни
в преобразовании итогового балла.

Каждому положительному товару назначены четыре отрицательных. Сначала выбираются
ближайшие отрицательные с тем же замороженным набором шести признаков, затем —
ближайшие среди всех разрешённых отрицательных. Близость считается по символьным
фрагментам названия и описания только внутри обучающей части. Один отрицательный
товар используется не более восьми раз, а равенства разрешаются строковым
идентификатором товара.

Итоговые манифесты уже созданы и проверены:

- fold 0: 336 пар, 84 положительных товара, 116 разных отрицательных;
- fold 3: 360 пар, 90 положительных товаров, 121 разный отрицательный;
- в парах нет строк проверочного fold и строк, запрещённых защитой связанных
  семейств;
- сохранены контрольные суммы файлов и порядка пар.

Манифесты не содержат исходные тексты, ссылки на изображения или данные доступа.

## Обучение

Используется проверенный в опыте `300` нативный загрузчик InternVL3.5-2B. Модель
получает первое изображение размером `448 × 448`, название и описание. Башня
изображений заморожена. Обучаются только небольшие добавки ранга 16 в механизме
внимания языковой части.

Полный архив изображений не нужен. Единственный разрешённый источник для
двухfoldовой проверки — поле `image_url` в том же замороженном манифесте на 909
товаров. До загрузки модели все изображения, нужные выбранному fold, скачиваются
параллельно в локальный cache. Для каждого товара разрешены ровно три попытки.
Каждый файл обязательно декодируется как RGB и повторно проверяется после
сохранения. Если отсутствует хотя бы одно изображение или оно не декодируется,
обучение прекращается до обращения к GPU. Белые и любые другие подстановочные
изображения запрещены. В отчёт попадают только количества загрузок, попыток,
ошибок и попаданий в cache; исходные ссылки не сохраняются и не печатаются.

Для товара считается разность между оценками следующего ответа `1` и `0`.
Функция потерь увеличивает эту разность у положительного товара относительно
парного отрицательного. Зафиксировано ровно 96 шагов оптимизатора, размер группы
четыре пары и накопление градиента по четырём группам. Скрипт принимает только
заранее объявленные folds `0` и `3` и отказывается перезаписывать результаты.

Пример точки входа; в рамках подготовки опыта команды не запускались:

```bash
python experiments/530_internvl_pairwise_flammable_ranker/train_screen.py \
  --fold 0 \
  --selector-manifest /path/to/frozen-selector.csv.gz \
  --image-source manifest \
  --image-cache /path/to/fold-0/image-cache \
  --model-root /path/to/model \
  --output-dir /path/to/fold-0
```

## Как считается проверочный результат

Необработанный балл InternVL переводится в ранг через эмпирическое распределение
баллов разрешённых обучающих товаров без использования их меток. Только для
выбранных товаров проверочного fold применяется заранее заданная формула:

`score_candidate = score_400 + 0.10 × (rank_internvl − rank_qwen3vl)`.

Пороги заморожены до обучения: `0.9564604759216309` для fold 0 и
`0.9570291638374329` для fold 3. Оценщик проверяет контрольные суммы манифестов,
точные параметры обучения, состав обучающих и проверочных строк и неизменность
ответов БАД.

```bash
python experiments/530_internvl_pairwise_flammable_ranker/evaluate_screen.py \
  --fold-0 /path/to/fold-0/internvl_scores.csv \
  --fold-3 /path/to/fold-3/internvl_scores.csv \
  --output-dir /path/to/screen-evaluation
```

Нулевой контроль уже пройден: исходный ранг Qwen3-VL даёт ноль изменённых
ответов и точно восстанавливает Macro F1 `0.9312591699999442` на fold 0 и
`0.9166759475813936` на fold 3.

## Условия продолжения

Опыт немедленно отклоняется, если хотя бы один fold не улучшился, средний прирост
Macro F1 меньше `0.003`, выросло число пропущенных положительных или опасных
товаров, ухудшения слишком часты либо прирост не подтверждается на безопасных
связанных компонентах. Для компонентов используется 10 000 повторов с seed
`48042`; требуемая вероятность положительного прироста — не ниже `0.80`.

Успешная проверка не разрешает отправку решения. Она разрешает лишь обучение
оставшихся трёх folds по неизменному рецепту. Сейчас обучение и модельный
инференс не запускались.
