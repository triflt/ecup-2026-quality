# Experiment 684 — stronger flammable teacher LoRA

Status: `BLOCKED_PENDING_685A_RANK_MECHANISM`. GPU jobs: `0`. Public: `0`.

## Objective

After the cheap 685A rank-transfer test, train and qualify a multimodal Qwen-family LoRA teacher that is demonstrably
stronger than the accepted Qwen3.6-27B flammable probe. The teacher is offline
only: its base model, adapter and runtime are forbidden from the competition
submission. A passed teacher supplies targets to the deployable 4B student in
experiment 685.

Teacher scale is deliberately not the first new factor. Experiment 681 failed
because saturated in-sample logits were transferred as absolute binary targets;
it did not show that the current teacher lacks useful knowledge. Experiment
685A first reuses the already accepted teacher scores with a magnitude-invariant
pairwise objective. This experiment opens only after that mechanism test.

The current Qwen3.6-27B signal is the frozen control: five-fold routed
flammable F1 `0.9075144509`, tie-aware pooled AP `0.9195422257` for the 27B
standalone scores and corrections/regressions `25/3` for the accepted equal-logit
offline route. A larger parameter count is not an acceptance criterion.

## Candidate order

1. `Qwen/Qwen3.8-27B`: same scale but a stronger/newer multimodal Qwen. Its old
   train attempt was infrastructure-blocked by missing fast kernels and fallback
   OOM; it was not quality-rejected. Reuse the now proven immutable-bundle,
   exact-model-revision and controlled-runtime discipline. The only scientific
   factor versus the Qwen3.6-27B teacher is the backbone/revision.
2. `Qwen/Qwen3.5-122B-A10B`: a larger multimodal MoE teacher. Open only after a
   CPU package/model-registry audit and a max-shape forward/backward LoRA smoke.
   It must beat the 27B teacher, not merely fit on the hardware.
3. Any still larger teacher is blocked unless the first two fail the quality
   gate and an exact supported runtime plus bounded GPU budget is proven.

Official model cards:

- https://huggingface.co/Qwen/Qwen3.5-122B-A10B

## Frozen comparison

- semantic-family-v3 outer folds; screen `0/3`, confirmation `1/2/4`;
- same outer-train row multiset, image view, prompt, hard labels, seed, one
  epoch, effective batch, optimizer schedule, LoRA rank/alpha/dropout and
  threshold as the current 27B teacher whenever the architecture permits exact
  parity;
- raw score is `logit("1") - logit("0")`;
- BAD is diagnostic only; the teacher is qualified for flammable and is never
  a production route;
- no Public, sealed labels or outer-fold threshold tuning.

If architecture forces a runtime-only change, prediction parity on a fixed
max-shape smoke is required before the screen. A new objective or causal schema
is a separate experiment, not folded into this architecture comparison.

## Qualification gate

Screen folds 0/3 must both improve tie-aware flammable AP over Qwen3.6-27B;
mean AP delta must be at least `+0.010`, routed Macro must not fall on either
fold, flammable FN must not increase and corrections/regressions must be at
least `1.5`.

Full acceptance requires AP wins on at least 4/5 folds, mean AP delta at least
`+0.010`, pooled routed flammable F1 at least `0.915`, pooled FN no higher than
the current teacher route, positive singleton-family delta and bootstrap
`P(gain > 0) >= 0.90`. Failure closes that teacher; no teacher-size exception.

## Leakage-safe target requirement

A qualified model is not yet a distillation dataset. For student outer fold
`k`, all targets must be generated by teachers whose training excludes outer
fold `k`. Targets for student outer-train rows must additionally be nested
cross-fitted inside outer-train, or the explicit in-sample limitation must be a
separate ablation. Ordinary five-fold OOF merging for outer student CV remains
forbidden because teacher parameters can carry labels from student outer
validation into student training targets.

## Budget gate

- Qwen3.8 screen: one technical smoke, then at most `2 x 4 H100` folds.
- 122B screen: no live job before measured memory/runtime smoke; use the
  smallest supported tensor/FSDP topology and cap the first screen to folds
  0/3.
- Stop immediately if the model cannot produce finite, occurrence-bound raw
  logits or if projected target generation cannot finish within the available
  competition research window.
