# 653: техническая проверка LoRA для Qwen3.6-27B

Статус: **четырёх-GPU технический smoke пройден; эксперимент 654 разрешён**.

Эксперимент проверяет только техническую возможность обучения большой
мультимодальной Qwen на зрелом runtime, уже прошедшем prompting в эксперименте
`651`. Он не читает данные соревнования и не является сравнением качества.

Один процесс размещает неизменяемую `Qwen3.6-27B` на четырёх GPU, добавляет
rsLoRA rank 16 к проекциям `q/k/v/o` и на двух синтетических карточках обязан
выполнить:

1. загрузку модели без CPU/disk offload;
2. настоящий multimodal forward и backward;
3. конечный classification loss и градиенты;
4. один optimizer step;
5. сохранение и повторную загрузку адаптера;
6. конечную оценку после reload;
7. выпуск ZIP, отчёта и контрольных сумм.

Применяется model-parallel размещение внутри одного четырёх-GPU задания, а не
несколько несинхронизированных процессов. Это минимальный тест, который может
опровергнуть рабочесть fallback до запуска folds `0/3`.

При успехе создаются отдельные научные эксперименты для `class-only` и
`class+evidence`. При неуспехе меняется только подтверждённый технический
фактор; данные, loss и критерии будущего сравнения не затрагиваются.

Основания: успешный prompting `Qwen3.6-27B` в `651`, официальный model card и
правила технического preflight из локальной документации вычислительной
платформы.

Проверка завершилась без CPU/disk offload: модель увидела четыре GPU, выполнила
два конечных forward/backward, один шаг оптимизатора, сохранила и повторно
загрузила адаптер. Оценка после reload конечна. Внешний и внутренний ZIP прошли
контроль целостности; этот результат является только техническим допуском и не
содержит метрик качества соревнования.

```bash
python experiments/653_qwen36_27b_lora_runtime_preflight/technical_smoke.py --help
```
