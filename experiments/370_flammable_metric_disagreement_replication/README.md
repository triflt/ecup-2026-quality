# 370: репликация flammable hard-negative disagreement

## Статус гипотезы

Это новая exploratory-ветка, сформулированная после отклонения `360`. В
исторической диагностике learned metric ошибалась на BAD, но среди верхних 10%
flammable-разногласий дала 7 исправлений против 2 ухудшений. Эти числа не считаются
валидацией и не входят в acceptance.

## Замороженная репликация

- BAD, unsafe и non-flammable строки неизменны;
- для каждого outer fold каждой из трёх заранее созданных
  `connected_family_repeated_v1` topology метрика полностью переобучается только
  на flammable donors;
- family prototypes, hard same/opposite pairs, LogisticRegression `C=0,1`, 256
  координат и seed `36042` совпадают с механизмом `360`;
- среди внешних строк рассматриваются только разногласия metric против production
  `190`; меняются верхние 10% этих разногласий по абсолютному metric score;
- quantile использует только внешние scores, не метки; минимум одна строка на fold;
- posthoc historical 7/2 остаётся только motivation и не пересчитывается как
  независимый результат.

Для продолжения нужны: положительная Macro/flammable разница на каждой из трёх
replications, средняя Macro `>= +0,001`, не менее 11 из 15 выигранных folds,
corrected:regressed `>= 2` суммарно и не ниже 1 на каждой topology, component
bootstrap `P >= 0,80` на каждой, ноль изменений BAD/unsafe. Иначе ветка закрывается
без full refit и пакета.

## Итог

Замороженное правило не прошло критерии принятия:

- Macro delta по трём повторениям: `−0,000225`, `+0,002386`, `+0,005248`;
- средняя разница `+0,002469`, но победы только `6/15` разбиений;
- исправлено 22 решения, ухудшено 13, отношение `1,69 < 2`;
- bootstrap `P(delta > 0)`: `0,4818`, `0,7046`, `0,9054`;
- БАД и unsafe-компоненты не изменились.

Эксперимент отклонён формально, full refit и пакет не создаются. Положительный
средний эффект на двух из трёх новых топологий сохраняется как перспективный, но
нестабильный сигнал. Следующая проверка обязана использовать представление,
совпадающее с production-пайплайном `190`: текущая ветка работала с кешем только
первого изображения, тогда как `190` объединяет все доступные изображения товара.
