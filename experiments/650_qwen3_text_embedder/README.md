# 650: компактный текстовый эмбеддер против TF-IDF

Статус: **отклонён на заранее зафиксированном экране folds 0/3**.

## Гипотеза

TF-IDF хорошо запоминает буквальные формулировки, но хуже переносит смысловые
варианты отрицаний, состава и комплектности. Компактный мультиязычный эмбеддер
может дать устойчивые семантические признаки, не увеличивая стоимость
мультимодального инференса.

Выбран `Qwen/Qwen3-Embedding-0.6B`, revision
`97b0c614be4d77ee51c0cef4e5f07c00f9eb65b3`. Официальная карточка указывает
0,6 млрд параметров, 100+ языков, размерность 1024 и сильные результаты MTEB
Multilingual. Источники:

- <https://huggingface.co/Qwen/Qwen3-Embedding-0.6B>
- <https://github.com/QwenLM/Qwen3-Embedding>

## Последовательность

1. Один label-blind GPU-проход строит нормированные эмбеддинги всех 11 118
   development-строк. Sealed и метки физически отсутствуют.
2. Zero-shot вариант сравнивает строку с четырьмя заранее заданными прототипами
   правил и не использует обучающие метки.
3. Frozen-supervised вариант обучает `LinearSVC(C=1)` по отдельности для каждой
   категории внутри внешнего semantic-family fold.
4. Контроль TF-IDF использует тот же внешний fold и тот же `LinearSVC`; словарь
   и IDF строятся только на соответствующем train.
5. Сначала открываются folds 0/3. Дообучение эмбеддера и интеграция в 140
   разрешены только при положительном результате на обоих folds и наличии
   исправлений, которых нет у текущих Qwen-компонент.

## Критерий остановки

Ветка закрывается, если supervised frozen-эмбеддер не выигрывает оба screen
fold, средний прирост меньше `0,0015`, падает категория больше `0,002` или
исправления полностью дублируют существующий ансамбль.

## Результат

Прямая доставка точной ревизии успешно построила 11 118 нормированных
эмбеддингов размерности 1024; все значения конечны, метки и sealed-строки модель
не читала. На fold 0 компактный эмбеддер проиграл TF-IDF `−0,115927` Macro F1,
на fold 3 — `−0,047743`. Совокупно ухудшились обе категории: БАД `−0,035474`,
легковоспламеняющиеся `−0,133887`; исправлено 121 решение против 281
ухудшенного. Все четыре frozen gate провалены.

Дообучение эмбеддера и интеграция в 140 не запускаются: уже замороженное
представление даёт сильный отрицательный результат на обоих независимых
экранах. TF-IDF сохраняется как текстовая компонента.
