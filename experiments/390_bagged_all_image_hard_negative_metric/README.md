# 390: ансамблевая all-image hard-negative метрика

## Гипотеза

В `370` и `380` средний эффект hard-negative метрики был положительным, но знак
менялся между connected topology. Проверяем, вызвана ли нестабильность отдельными
donor families: для каждого outer fold обучаем три метрики на независимых
стратифицированных подвыборках 80% семейств и меняем решение только при полном
согласии направлений.

## Замороженный протокол

- all-image embeddings из production-compatible задачи;
- seeds `39041`, `39042`, `39043`;
- 80% согласованных donor families отдельно для каждого класса и seed;
- одинаковые hard-pair objective, 256 координат и `C=0,1`;
- только flammable; BAD, unsafe и non-flammable неизменны;
- среди единогласных разногласий с `190` меняются верхние 10% по минимальному
  абсолютному margin трёх моделей;
- три заранее созданные connected topology, без подбора порога.

Критерии: каждое повторение положительно, среднее Macro не ниже `+0,001`, не
меньше `10/15` побед, суммарно не меньше двух исправлений на одно ухудшение,
отношение не ниже единицы и bootstrap `P(delta>0) >= 0,75` на каждом повторении,
нулевые изменения BAD и unsafe.

## Итог

Ансамбль сохранил положительное среднее, но не прошёл gate:

- Macro delta: `+0,004077`, `−0,001105`, `+0,001486`;
- среднее `+0,001486`, победы `7/15`;
- исправлено 15, ухудшено 9;
- bootstrap `P(delta > 0)`: `0,8756`, `0,3828`, `0,6590`.

Внутри-fold подвыборка использует около 64% всех доступных donor families и,
вероятно, теряет слишком много опорных примеров. Порог, долю и seeds после
результата не меняем; full refit и submission не создаются.
