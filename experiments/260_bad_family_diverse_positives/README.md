# 260: Разнообразные положительные семейства БАД

## Гипотеза

Исходное обучение выбирает 1 500 положительных строк БАД, но они представляют лишь 1 231–1 260 независимых семейств. В результате 240–269 мест заняты повторами. У текущего двухseedового лидера на положительных БАД остаётся 273 ошибки, из них 181 приходится на одиночные семейства. Отбор 1 500 разных семейств должен расширить покрытие формулировок и упаковок без роста времени обучения и применения.

## Единственный изменяемый фактор

Половина положительной корзины по-прежнему состоит из сложных примеров, половина — из случайных. Вместо строк выбираются семейства, по одной строке из каждого. Контрольный построчный отбор всё равно выполняется и расходует тот же поток случайных чисел; поэтому отрицательные БАД и обе flammable-корзины полностью совпадают с родительским обучением.

Аудит `analysis/isolation_audit.json` подтвердил это на всех пяти разбиениях: вне положительных БАД мультимножества обучающих индексов совпали точно, а целевая корзина содержит 1 500 разных семейств.

## Как работает новая выборка

Родительский алгоритм выбирает 1 500 положительных строк БАД: 750 самых трудных для прежней системы и 750 случайных из остальных. Трудность измеряется расстоянием до порога: чем ближе оценка к порогу, тем менее уверена прежняя система. Поскольку единицей отбора служит строка, несколько почти одинаковых карточек одного товара могут занять несколько мест.

В `260` единицей отбора становится семейство. Для каждого семейства находится его самая неоднозначная строка; по ней определяется трудность всего семейства. Затем выбираются 750 самых трудных разных семейств и 750 случайных разных семейств из оставшихся. От каждого выбранного семейства берётся одна строка. Число положительных предъявлений, соотношение классов и число обновлений не меняются.

## Схема проверки и итогового обучения

Пять адаптеров нового seed `42` обучаются на четырёх групповых частях и предсказывают пятую. После соединения пяти непересекающихся прогнозов новый seed `42` усредняется по вероятностям с неизменным seed `31415`; веса и пороги для каждой проверяемой части определяются без её меток.

По результату выбирается рецепт семейно-разнообразного отбора, а не один из пяти адаптеров. Шестой адаптер обучается на всех данных и не участвует в проверочной оценке. Если рецепт пройдёт критерии, этот полный адаптер заменит прежний seed `42` в архиве отправки.

## Отличие от лучшего Public-решения `190`

Public-решение использует один Qwen3.5 seed `42` и выбирает положительные примеры БАД построчно. `260` сначала наследует усреднение двух seed из `230`, затем меняет только положительную корзину нового seed `42`: каждое из 1 500 мест представляет отдельное семейство. Текстовая модель, обе модели Qwen3-VL, второй Qwen3.5 seed, отрицательные примеры, легковоспламеняющаяся категория и все семейные правила применения остаются неизменными.

Эксперимент запущен параллельно с `241` как независимая однофакторная проверка относительно `230`: семейный баланс положительных flammable-примеров выключен. Если оба фактора будут приняты отдельно, их сочетание потребует отдельной подтверждающей проверки; результаты нельзя складывать арифметически.

## Проверка

Новый seed `42` заменяет родительский seed `42` в среднем вероятностей с неизменным seed `31415`. Требования: не меньше `+0.001` Macro F1, победа хотя бы на четырёх из пяти внешних разбиений и падение любой категории не больше `0.005`.

Адаптеры хранятся локально. Разрешённый удалённый путь — только `s3://private-artifact-store/private-prefix/`.

## Результат

В паре с неизменным seed `31415` эксперимент получил nested grouped Macro F1 `0,921312` против `0,919237` у `230`, то есть `+0,002075`. BAD вырос на `0,000163`, flammable — на `0,003987`. Однако улучшены только три из пяти внешних разбиений, а групповой bootstrap даёт `P(прирост > 0) = 0,6616` и 95%-й интервал `[-0,00750; 0,01202]`.

По заранее заданному критерию эксперимент отклонён. Результат остаётся полезным слабым сигналом в пользу разнообразия положительных семейств БАД, но его нельзя считать кандидатом на отправку: родитель `230` провалился на Public, а прирост `260` неустойчив между разбиениями. Полный адаптер и построчные прогнозы сохранены локально для анализа.

## Повторная проверка внутри Public-лидера

После провала `230` создан протокол `locked_190_nested_v1`: он возвращает неизменные веса и число проходов подтверждённого решения `190` и заменяет только Qwen3.5-адаптер. В этой проверке `260` получил Macro F1 `0,930613` против `0,923409`, прирост `+0,007204` и четыре победы из пяти. Компонент принят для архива `280_bad_family_diverse_public190`; исходный результат относительно двухseedового `230` остаётся в истории и не переписывается.

## Разбор ошибок относительно Public-архитектуры 190

В `locked_190_nested_v1` изменены 97 из 12 971 решений: исправлены 42 и ухудшены
55. Для flammable ошибок стало 36 вместо 44; сильнейшие улучшения относятся к
газовым товарам, горелкам и жидкостям для розжига. При этом ошибок БАД стало 523
вместо 502, особенно на спортивном питании. Воспроизводимый отчёт и построчные
таблицы находятся в `analysis/locked_190_errors/`.

## Public-проверка компонента

В эксперименте `280` этот полный адаптер был единственным изменением относительно
`190`. Public Macro F1 составил `0,8919244237` — столько же, сколько у `190`, до
отображаемой точности. Поэтому компонент не принимается в рабочее решение и
сохраняется только для воспроизводимого разбора ошибок. Равный итоговый F1 не
доказывает равенство отдельных прогнозов; пороги по этому результату не менялись.

Повторное донорное воспроизведение всех downstream-правил показало, что после
exact/name/numeric-family/shingle priors сохраняются 92 из 97 изменений адаптера,
то есть `94,8%`. Локальная разница Macro F1 при этом меняется с `+0,007204` на
`+0,007358`. Следовательно, правила не маскируют сигнал `260`; наиболее вероятны
сдвиг распределения скрытых товаров и накопленный выбор гипотез по одним и тем же
пяти разбиениям. Отчёт: `analysis/locked_190_errors/decision_survival_report.json`.
