# 643: Qwen3.5-4B, класс + проверяемое доказательство

Статус: **подготовлен, не запущен**.

Модель сохраняет отдельный основной atomic-verdict loss из `641` и добавляет
auxiliary causal loss веса `0.05` на короткий JSON с verdict, exact quote и
закрытым типом признака. Это новый механизм относительно неудачных `520/570`:
длинный suffix больше не заменяет и не размывает основной classification loss.

Один адаптер получает поровну два auxiliary порядка:

1. `class_first`: сначала класс, затем доказательство;
2. `evidence_first`: сначала доказательство, затем класс.

При оценке `class_first` verdict берётся из исходного atomic prompt. Для
`evidence_first` модель сначала генерирует доказательство, оно проходит строгую
проверку, и только затем проверенное доказательство добавляется к atomic
verdict prompt. Так сравнение действительно отвечает на вопрос, помогает ли
доказательство решить задачу, а не только красиво комментирует ответ.

Quote принимается лишь как единственная точная подстрока названия/описания либо
как точный текст единственной OCR-области. Модель не генерирует координаты:
image/region/polygon присоединяются проверяющим кодом из OCR sidecar. Всё
неразрешимое превращается в `NO_EVIDENCE`.

Контроль — `641`. Вход модели и preprocessing неизменны; OCR используется как
label-blind проверка выхода, но не добавляется в prompt. Runtime намеренно не
строится до готовности полного checksum-locked OCR sidecar эксперимента `633`.
