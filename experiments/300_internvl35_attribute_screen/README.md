# 300: Структурированные flammable-признаки с InternVL3.5-2B

## Гипотеза

Ошибки сильнейшего решения сосредоточены не в общем распознавании товара, а в
различении горючего содержимого и внешне похожего оборудования. Независимая
InternVL3.5-2B должна извлекать пять наблюдаемых признаков: газ, горючая жидкость,
источник огня, пустое оборудование и наличие горючего содержимого в комплекте.
Эти признаки будут отдельным компонентом; text, Qwen, классификаторы и семейные
priors эксперимента `190` не заменяются.

## Почему эта модель

Официальная карточка указывает около 2,35 млрд параметров, OCR/document data и
динамическое разбиение изображения на блоки 448×448. Это отличается от визуального
пути Qwen3.5 и MiniCPM. Победитель Rakuten SIGIR 2020 подтверждает пользу
независимых модальных компонентов и позднего объединения решений.

## Проверка

Сначала выполняется один backward smoke на настоящем изображении. Успех только
подтверждает совместимость. Затем допускается заранее зафиксированная дешёвая
проверка на контрастных folds, а полный кандидат оценивается по
`component_transfer_gate_v1`: все пять folds, downstream priors, групповой
bootstrap и повтор лучшего/худшего fold с seed `31415`.

До отдельной проверки качества и времени компонент не включается в архив отправки.

## Результат

Первая проверка `redacted-job` завершилась до загрузки модели: bootstrap
повторно использовал старый каталог Transformers 5.7 без зависимости `requests`,
хотя для опыта была запрошена версия 4.57.3. Инициализация модели в Model
Registry прошла успешно. Повтор разрешён только с отдельным каталогом
`transformers4573_full`; это исправляет подтверждённую инфраструктурную причину,
не меняя модель или проверяемую гипотезу.

Вторая проверка `redacted-job` подтвердила установку изолированной версии,
но завершилась ещё до загрузки модели: скрипт безусловно импортировал
`AutoModelForMultimodalLM`, которого нет в Transformers 4.57.3, хотя ветке
InternVL нужен только доступный `AutoModelForImageTextToText`. Следующий повтор
разрешён с ленивым разрешением неиспользуемого класса; вычислительный рецепт снова
не меняется.

Третья проверка `redacted-job` установила окончательное различие форматов:
выбранный разрешённый checkpoint — InternVL GitHub format. Его официальный путь
использует `AutoModel`, `AutoTokenizer(use_fast=False)` и явное преобразование
изображений 448×448; универсальный `AutoProcessor` относится к HF-format модели.
Поэтому generic smoke больше не повторяется. Подготовлен нативный backward с тем
же разрешённым checkpoint и LoRA только на attention-проекциях language model.

Нативная проверка `redacted-job` прошла: 2.3548 млрд параметров, 6.4225 млн
обучаемых LoRA-параметров, loss `4.96875`, 224 градиентных тензора, норма
`119.1998`, пик памяти `4.844 GiB`. Совместимость подтверждена.

Следующий этап — не прямое предсказание итоговой метки. Для заранее выбранных
label-blind неуверенных flammable-строк модель выдаёт шесть бинарных атрибутов:
топливо/газ, пустое оборудование, источник огня, топливо в комплекте, горючий
материал и явное отсутствие. Gate обучается только на donor-folds; остальным
строкам сохраняется решение 190.

Первый вывод `redacted-job` успешно обработал все 909 строк за 1,19 минуты,
без ошибок загрузки изображений, но не прошёл проверку формата: 214 ответов
содержали слитный шестибитный код, 162 — однозначные шесть цифр с разделителями,
а 484 оборвались после одной цифры. Поэтому метрика качества по этому файлу не
считается. Повтор `redacted-job` меняет только сериализацию: требует не менее
шести новых токенов, явно задаёт префикс `КОД` и принимает ровно шесть цифр с
разделителями. Набор 909 строк и semantic-вопросы не изменены.

Повтор успешно дал 573 валидных ответа из 909 за 1,63 минуты. Честный gate для
каждого внешнего fold обучался только на остальных folds; 336 строк с невалидным
форматом сохранили исходное решение `190`. Итоговый Macro F1 снизился с
`0,923409` до `0,916836` (`-0,006572`), flammable F1 — с `0,892157` до
`0,879012`. Побед `2/5`; из 13 изменённых решений исправлены 4 и ухудшены 9;
grouped bootstrap даёт `P(прирост > 0)=0,0742` и интервал
`[-0,01681; 0,00248]`.

Гипотеза отклонена. InternVL не добавляется к отправке и полный вывод по всем
flammable-строкам не запускается. Отрицательный результат относится к этому
zero-shot набору атрибутов и линейному donor-only gate, а не к совместимости
модели вообще.
