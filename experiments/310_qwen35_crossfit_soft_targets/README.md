# 310: Qwen3.5 с перекрёстно полученными мягкими целями

## Гипотеза

Вместо жёсткого ответа `0` или `1` Qwen3.5 получает при обучении вероятность,
полученную ансамблем 190 вне обучающего разбиения этой строки. Неуверенный или
противоречивый товар поэтому не заставляет модель становиться чрезмерно уверенной
в одной метке. Архитектура, первое изображение, разбиения и итоговое объединение
190 остаются неизменными; дополнительного прохода модели на отправке нет.

## Защита от утечки

Для каждой строки и модели-учителя использован прогноз outer fold, на котором
строка не обучалась. Калибратор вероятности также обучался только на остальных
четырёх folds. Файл `research/qwen35_crossfit_soft_targets.csv` имеет SHA256
`392b1d098883ecf0c5de7c250bb4e9dd8ac8d296c8ef39b766e27b9fa2a5d007`.

## Проверка

Сначала выполняется один backward smoke с мягкой целью `0.2` на настоящем
изображении. Затем рецепт допускается к пяти grouped folds. Честное решение
принимается по locked-архитектуре `190`, connected-safe строкам, групповому и
компонентному bootstrap, replay всех downstream priors и заранее замороженным 243
sports-ошибкам. Глобально подобранное fusion сохраняется только как диагностика.

## Результат

Проверка `redacted-job` успешно выполнила настоящий backward: loss
`1.0484445`, 64 тензора градиентов, норма `59.3924`, пик памяти `8.755 GiB`.
Разрешён пятираздельный цикл; folds и полный адаптер запускаются попарно на двух
H100, но каждый процесс по-прежнему использует ровно одну карту.

Первый двухкарточный запуск показал `6.97–7.13` минуты на 25 из 337 updates:
неоптимизированный soft-loss материализовал logits всего словаря для каждой
позиции, хотя использовал только последний ответ. Такой цикл не помещался в лимит
4 часа. Включён нативный параметр Qwen3.5 `logits_to_keep=1`; он сохраняет тот же
binary loss, но вычисляет только последний logit. Частичный запуск без checkpoint
не используется как результат.

Оптимизированный цикл `redacted-job` успешно завершил все пять folds и full
refit без ошибок загрузки. Архив сохранён локально в
`artifacts/compute_qwen_soft_b91s2l/`; SHA-256 внешнего ZIP:
`e2e2ff3628291033cc7dfb097e0e5f84439558ca95dcf65b33fe277c615b7340`, full
adapter:
`967af97a70a4111bec5d1757374cdeefa0a57c83c128e1ed2da86e69567ba3ca`.

## Итог

Гипотеза отклонена:

- locked Macro F1 `0,911246` против `0,923409`, разница `−0,012163`;
- победа только на одном из пяти folds;
- БАД `−0,001516`, легковоспламеняющиеся `−0,022810`;
- grouped bootstrap `P(прирост > 0)=0,0345`;
- на 11 207 connected-safe строках разница `−0,012827`, победа `1/5`;
- downstream priors сохраняют 96,5% изменений и итоговую отрицательную разницу
  `−0,012117`, поэтому они не маскируют локальное улучшение;
- исправлено лишь 6 из 243 замороженных sports-ошибок, при этом в cue-когорте
  создано 13 новых против 9 исправленных.

Мягкие цели уменьшили полезную специализацию редкого класса и особенно ухудшили
легковоспламеняющиеся товары. Full adapter остаётся исследовательским компонентом,
но не включается в отправку. Последующая ветка 320 была выполнена и также
отклонена; её компактный terminal result сохранён в
[`docs/research/archive/removed-experiments-through-652.md`](../../docs/research/archive/removed-experiments-through-652.md).
