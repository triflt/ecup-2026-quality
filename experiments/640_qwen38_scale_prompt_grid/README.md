# 640: честное сравнение prompting Qwen 4B и 27B

Статус: **технический smoke 27B запущен на 20 строках**.

Это первая строка полной сетки `размер × способ обучения`. Здесь обе модели
работают без обучения и получают один и тот же первый снимок, название,
описание, категорийное правило и формат ответа.

## Единственный изменяемый фактор

- `Qwen3.5-4B`, revision `851bf6e806efd8d0a36b00ddf55e13ccb7b8cd0a`;
- `Qwen3.8-27B`, revision `1d4bf0f2ff6012fd82039f2fa52739d0dd7c60c0`.

Thinking отключён. Вместо хрупкого разбора генерации используется разность
логитов следующего токена `1` и `0`. Порог равен нулю и не подбирается по
валидации. Это чистая zero-shot проверка масштаба модели.

Официальный model card описывает Qwen3.8-27B как нативную мультимодальную
плотную модель на 27 млрд параметров и поддерживает отключение thinking:
<https://huggingface.co/Qwen/Qwen3.8-27B>.

## Протокол

1. Label-blind технический smoke на 20 строках проверяет модельный класс,
   processor, токены `0/1`, память и схему выхода.
2. После успешного smoke обе модели обрабатывают все 11 118 development-строк.
3. Scores объединяются только по зафиксированному global index и проверяются на
   folds 0/3. Остальные folds открываются только если 27B проходит экран.
4. Никакие варианты промпта после просмотра метрик не перебираются.
5. Результат сравнивается только с другой prompting-моделью. Он не сравнивается
   напрямую с обученной компонентой 623 или полным ансамблем 140.

Следующие карточки сетки должны использовать тот же label-blind scope и prompt:
class-only 4B/27B и evidence-reasoning 4B/27B.
