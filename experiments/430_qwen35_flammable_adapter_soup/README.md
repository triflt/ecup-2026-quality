# 430: однопроходная интерполяция flammable-адаптера

## Гипотеза

Адаптер `260` даёт сильный локальный прирост для категории
«Легковоспламеняющиеся», но его жёсткая маршрутизация в `400` всё ещё теряет
часть положительных товаров. Эксперименты `410` и `420` показали, что новые
градиентные шаги и изменение корзины делают модель ещё более консервативной.

Проверяется другой механизм без обучения: эффективные LoRA-изменения исходного
адаптера `190` и адаптера `260` линейно интерполируются. Для БАД остаётся чистый
адаптер `190`; для flammable применяется один объединённый rank-32 адаптер и один
проход Qwen3.5.

## Замороженный протокол

До прогнозов зафиксированы доли адаптера `260`: `0`, `0,25`, `0,50`, `0,75`, `1`.
Крайние точки уже существуют как OOF-компоненты `190` и `260`; три промежуточные
точки считаются независимо. Матрицы `B@A` не приближаются: два rank-16 изменения
точно представляются одним rank-32 адаптером через конкатенацию факторов с
масштабами `(1-alpha)` и `alpha`.

Для каждого внешнего fold доля и flammable-порог выбираются только на остальных
четырёх fold; при равенстве выбирается меньшая доля `260`. Веса `0,15/0,10/0,75`,
BAD-ветка, priors и все остальные части `400` заморожены. Доля итогового полного
адаптера выбирается по всему OOF только после завершения внешней оценки.

## Критерии

- Macro F1 относительно `400` не ниже `+0,003`;
- flammable F1 не ниже `+0,006`, БАД неизменен;
- победа не менее чем на `4/5` внешних fold;
- flammable и safety-union false negatives не растут;
- исправлений как минимум в 1,5 раза больше, чем ухудшений;
- connected-safe delta положительна, bootstrap `P(delta>0) >= 0,90`;
- после production priors сохраняется не менее 80% изменений и положительный
  итоговый прирост.

Неудача любого обязательного критерия отклоняет интерполяцию; доли не
перенастраиваются по результатам Public.

## Состояние

Протокол и alpha-grid были заморожены до промежуточных прогнозов. Все три
одно-GPU задачи `redacted-job`, `redacted-job` и
`redacted-job` завершились успешно. Для каждой доли проверены 5 502 OOF
строки, ZIP, SHA-256, порядок ID, fold, категории, метки и конечность оценок.

Nested-выбор на каждом из пяти внешних fold независимо выбрал долю `0,50`.
Итог относительно `400`:

- Macro `0,934830` против `0,931645`, разница `+0,003185`;
- flammable `0,915000` против `0,908629`, разница `+0,006371`; БАД неизменен;
- исправлено 7, ухудшено 5; flammable и safety-union FN уменьшились на 4;
- fold 0 и 3 улучшились, folds 1/2/4 не изменились: строгих побед `2/5`;
- connected-safe разница `+0,003348`, bootstrap `P(delta>0)=0,7334`.

Механизм положительный и alpha стабилен, но не прошёл три замороженных условия:
`4/5` побед, отношение исправлений к ухудшениям `1,5` (получено `1,4`) и
connected bootstrap `0,90`. Эксперимент отклонён как готовый кандидат; полный
адаптер, prior replay и архив отправки не создаются. Сигнал разрешено переносить
только в отдельно версионированную независимую проверку без изменения этой
карточки.
