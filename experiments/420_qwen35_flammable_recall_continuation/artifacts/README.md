# Локальные артефакты 420

Адаптеры и bundles не публикуются. Для каждого принятого файла фиксируются
источник, размер, SHA-256, родительский адаптер `260` и соответствующий fold.

Проверенные screen-адаптеры folds 0 и 3 сохранены в `screen_seed42/` только для
воспроизводимости. Оба fold провалили заранее заданный фильтр, поэтому полный
адаптер не обучался и кандидата на отправку у эксперимента 420 нет.
