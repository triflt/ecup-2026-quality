# 420: короткое дообучение flammable-адаптера на полноту

## Гипотеза

Маршрутизация `400` улучшила категорию «Легковоспламеняющиеся» за счёт адаптера
`260`, особенно на газе и топливе. Полный цикл эксперимента `410` показал обратный
устойчивый эффект от дополнительного давления отрицательных примеров: итоговый
flammable F1 снизился на `0,044993`. Следовательно,
наиболее вероятное ограничение текущего адаптера — недостаточная полнота редкого
положительного класса, а не недостаток разнообразия отрицательных товаров.

Проверяется один новый фактор: существующий адаптер `260` получает один короткий
flammable-only этап продолженного обучения с равным числом положительных и
отрицательных предъявлений. Архитектура `400`, prompt, rank LoRA, изображения,
пороги, веса, правила и один проход модели при применении не меняются.

## Замороженный рецепт до прогнозов

- для каждого внешнего разбиения загружается соответствующий адаптер `260/fold_k`;
- положительные connected-safe flammable-строки повторяются пять раз;
- выбирается такое же число разных отрицательных строк по стабильному SHA-256,
  без hard mining и без семейного перераспределения;
- один проход по этой корзине, AdamW `lr=2e-5`, weight decay `0,01`, те же batch,
  gradient accumulation и cosine schedule;
- связанные с внешним holdout строки исключаются маской
  `connected_family_guard_v2`;
- выбор строк не использует прогнозы `400`, его 26 изменённых решений или
  когорты ошибок. Manifest создаётся и получает контрольную сумму до первого
  прогноза кандидата.

## Связь с сильными решениями

Механизм соответствует двум устойчивым практикам для несбалансированной
классификации: короткое дообучение специалиста на целевом распределении и
сбалансированное повторение редкого класса. В отличие от отклонённого `241`, здесь
не перераспределяются положительные семейства при исходном обучении: меняется
только отдельная последующая стадия уже полезного flammable-компонента `260`.

## Дешёвый фильтр

Сначала считаются заранее выбранные контрастные folds `0` и `3`. Эксперимент
останавливается, если хотя бы на одном routed Macro delta относительно `400`
неположительна, растёт число flammable false negatives, исправлений не больше
ухудшений или снижается полнота объединённой защитной когорты
ignition/pyro/charcoal. Этот фильтр только отклоняет рецепт и не заменяет полную
оценку.

Порог в фильтре также зафиксирован до прогнозов. Для folds `0` и `3` используются
внеобучающие ранги продолженного адаптера; на folds `1/2/4` остаются ранги
родителя `260`. Порог каждого проверяемого fold выбирается без его строк на этом
гибридном OOF-наборе при неизменных весах `0,15/0,10/0,75`. Такой приближённый
порог достаточен только для ранней отбраковки. Даже успешные folds `0/3` не дают
права принять или собрать модель без полного пятираздельного цикла.

## Полная приёмка

- routed Macro delta относительно `400` не меньше `+0,003`;
- flammable F1 delta не меньше `+0,006`, БАД остаётся неизменным;
- не меньше `4/5` побед;
- flammable false negatives и полнота защитных когорт не ухудшаются;
- исправлено как минимум в `1,5` раза больше решений, чем ухудшено;
- connected bootstrap `P(delta>0) >= 0,90`;
- после production priors сохраняется не менее 80% изменений и положительная
  разница;
- при успехе folds `0` и `3` повторяются с RNG `31415`: среднее положительно,
  ни один повтор не хуже `−0,005`.

Проверочные модели выбирают рецепт, а не лучший fold. Только после прохождения
всех условий тот же рецепт продолжается от полного адаптера `260/full`; именно
полный адаптер может попасть в категорийную маршрутизацию отправки. Fold-адаптеры
в архив отправки не входят.

## Состояние

Рецепт и manifest были заморожены до прогнозов. Обе независимые одно-GPU задачи
`redacted-job` и `redacted-job` завершились успешно, а их
артефакты прошли проверку ZIP, контрольных сумм, состава и порядка 1 100
flammable-прогнозов на каждом fold.

Двухраздельный фильтр отклонил рецепт на обоих заранее выбранных разбиениях:

- fold 0: routed Macro `−0,026410`, 0 исправлений и 4 ухудшения, flammable FN `+3`;
- fold 3: routed Macro `−0,007801`, 0 исправлений и 1 ухудшение, flammable FN `+1`;
- на fold 3 число FN в safety-union также выросло на 1.

Ни один проверяемый fold не прошёл frozen gates. Полный пятираздельный цикл,
повтор seed, продолжение полного адаптера и сборка отправки запрещены. Вывод:
простое короткое продолжение на сбалансированной корзине не возвращает полноту
адаптера `260`, а делает его решения ещё более консервативными.
