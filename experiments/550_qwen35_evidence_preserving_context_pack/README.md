# 550: сохранение доказательств в длинных описаниях Qwen3.5

Статус: **двухfoldовый экран завершён и отклонён**. Fold 0 дал Macro delta
`−0,043457`, flammable FN `+6` и safety FN `+1`; fold 3 дал `+0,016189`,
flammable FN `−3` и safety FN `−3`. Среднее `−0,013634`, 6 исправлений против
10 ухудшений. Сильная смена знака подтверждает чувствительность механизма к
семейному составу; остальные старые folds, seed-повтор и full train запрещены.

## Проверяемая гипотеза

В решении `400` описание ограничено 1800 символами. Длинный текст сейчас
сокращается до 70% начала и 30% конца. Из-за этого доказательство правильной
категории может находиться в середине и не попадать в модель.

В опыте меняется только способ заполнить прежний предел в 1800 символов. Новый
вариант сохраняет начало и конец описания, а также полные предложения,
содержащие безопасные точные фрагменты из извлекателя опыта `490`. Модель,
изображения, обучающие строки, их повторения и порядок, число шагов, LoRA,
подсказка, веса решения и пороги не меняются.

## Почему упаковка не использует ответ

Извлекатель `490` запускается для каждого товара дважды с константами
`frozen_prediction=0` и `frozen_prediction=1`. Берётся объединение безопасных
точных фрагментов. Ни истинная метка, ни прогноз модели, ни номер fold в этот
выбор не передаются.

Если извлекатель обнаруживает конфликт, неоднозначное отрицание или
неоднозначную область действия, такие фрагменты не используются. Повторяющиеся
фрагменты удаляются. Предложение с доказательством включается целиком; обрывать
его запрещено.

Все символы итогового текста берутся из нормализованного исходного описания и
снабжены позицией в нём и точным интервалом в сыром поле до удаления HTML и
схлопывания пробелов. Разделители или многоточия не добавляются.
Исходная позиция не может использоваться дважды, итоговая длина не превышает
1800 символов.

## Двухfoldовая проверка

Обёртка принимает только folds `0` и `3`. Перед обучением она сверяет
контрольные суммы полного аудита и исходного trainer, а во время формирования
каждого текста — хеш текста и последовательности исходных позиций. Любое
расхождение прекращает запуск.

Команды подготовлены, но не выполнялись:

```bash
python experiments/550_qwen35_evidence_preserving_context_pack/train_screen.py \
  --fold 0 --output-dir /path/to/fold-0
python experiments/550_qwen35_evidence_preserving_context_pack/train_screen.py \
  --fold 3 --output-dir /path/to/fold-3
```

Оценщик заменяет только Qwen3.5-компонент категории
«Легковоспламеняющиеся» внутри маршрута `400`; ответы БАД должны остаться
побитово одинаковыми.

```bash
python experiments/550_qwen35_evidence_preserving_context_pack/evaluate_screen.py \
  --fold-0 /path/to/fold-0/lora_holdout_predictions.csv \
  --fold-3 /path/to/fold-3/lora_holdout_predictions.csv \
  --output-dir /path/to/evaluation
```

Нулевой контроль пройден: исходные прогнозы родительского Qwen3.5 дают ровно
ноль изменённых решений и полностью восстанавливают маршрут `400`.

Опыт отклоняется, если хотя бы один fold не улучшился, средний прирост Macro F1
меньше `0.001`, выросло число пропущенных положительных или опасных товаров,
исправлений не больше ухудшений, нет прироста на безопасных связанных семействах
либо изменился хотя бы один ответ БАД. Успешный экран разрешает только полный
пятиfoldовый цикл по неизменному рецепту, но не отправку решения.
