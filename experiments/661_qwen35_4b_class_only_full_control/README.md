# 661: полный пятираздельный контроль Qwen3.5-4B class-only

Статус: **открыты folds 1/2/4 после принятого экрана 641**.

## Зачем нужен эксперимент

659 смешивает логиты 4B и 27B только для категории легковоспламеняющихся. На
folds 0/3 смесь прошла все заранее записанные проверки, поэтому разрешены
оставшиеся разбиения 27B. Для честной полной оценки нужны и отсутствующие
class-only прогнозы 4B на folds 1/2/4.

661 не является новой модельной гипотезой. Это технически запечатанное
завершение контрольной ячейки 641:

- та же модель и revision;
- тот же class-only objective, seed, LoRA, learning rate и один epoch;
- тот же проверенный `legacy_eager` runtime;
- тот же memory-only micro-batch `2` и accumulation `8`, effective batch `16`;
- меняются только номер fold и соответствующие immutable runtime-строки.

Перед обучением runner проверяет continuation gate 661. Public, sealed и
validation labels не используются. Итог 661 сам по себе не является кандидатом
на отправку; он нужен только как полный контроль для 659 и scale-grid.
