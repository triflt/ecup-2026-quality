# Текущий статус проекта

Дата среза: 2026-08-29.

## Каноническое решение

**Решение 140** — лучший воспроизводимый результат на Public. Неизменяемый архив
получил Macro F1 **0.8923976821**. Полный пакет для ревью находится в
[`experiments/140_dual_lora_fusion/final/`](../experiments/140_dual_lora_fusion/final/),
а машинно-читаемый источник результата — [`reports/champion.json`](../reports/champion.json).

Классификационная часть зафиксирована. Объяснения, привязанные к признакам
карточки, проходят отдельный аудит и пока не считаются принятыми.

## Какая локальная оценка используется

В репозитории намеренно сохранены два несовместимых уровня оценки:

- `grouped_text_v1` и `nested_grouped_v1` — историческая CV-5 для честного
  воспроизведения и сравнения экспериментов, из которых собрано решение 140;
- `semantic_family_v3` — обязательная проверка новых архитектур: связанные
  товарные семейства не пересекают фолды.

Результаты разных протоколов нельзя складывать в одну таблицу. Текущий локальный
лидерборд новых кандидатов —
[`reports/semantic-v3-leaderboard.csv`](../reports/semantic-v3-leaderboard.csv).
Проверка на двух фолдах годится только для раннего отсева и не считается
результатом лидерборда.

## Почему встречаются разные CV-числа

| Значение | Протокол | Корректная интерпретация |
|---:|---|---|
| `0.9118425206` | вложенная групповая CV-5 | Слияние трёх компонентов до слоя памяти товаров |
| `0.942878` | вложенная симуляция повторов | Историческая оптимистичная оценка полного рецепта с памятью обучающей выборки |
| `0.8923976821` | Public-лидерборд | Фактический результат неизменяемого архива решения 140 |

`0.942878` не служит текущей оценкой переноса на новые семейства. Для новых
компонентов учитывается только полный повтор на `semantic_family_v3` с заранее
записанными критериями принятия.

## Важные подтверждённые выводы

- Две rsLoRA-ветки и опорный прогноз дают воспроизводимое вложенное слияние;
  точные команды и SHA OOF-артефактов записаны в
  [`REPRODUCE.md`](../experiments/140_dual_lora_fusion/final/REPRODUCE.md).
- Тяжёлые модели на 27B параметров дали полезный сигнал учителя, но не входят
  в отправляемое решение 140 из-за ограничений по размеру и времени.
- Отрицательные эксперименты сохраняются только тогда, когда есть терминальный
  измеренный результат и самостоятельный вывод. Незавершённые заготовки удалены.
- Public используется как проверка заранее замороженного архива, а не как
  источник подбора порогов после отправки.

## Что ещё требуется перед финальной публикацией

1. Опубликовать веса и их SHA в
   [`artifact-contract.json`](../experiments/140_dual_lora_fusion/final/artifact-contract.json).
2. Завершить отдельную проверку качества объяснений.
3. Повторить проверку схемы, времени и размера на финальном неизменяемом архиве.
4. Заполнить краткое название и объяснение решения в корневом README.

Исследовательские основания и архив перенесены в
[`docs/research/`](research/); оперативные журналы не являются частью
финального пакета решения.
