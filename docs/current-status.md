# Текущий статус проекта

Дата среза: 2026-08-29.

## Каноническое решение

**Решение 140** — текущий воспроизводимый Public-чемпион. Неизменяемый архив
получил Macro F1 **0.8923976821**. Полный пакет для ревью находится в
[`experiments/140_dual_lora_fusion/final/`](../experiments/140_dual_lora_fusion/final/),
а машинно-читаемый источник результата — [`reports/champion.json`](../reports/champion.json).

Классификационная часть зафиксирована. Evidence-grounded объяснения проходят
отдельный аудит и не считаются принятыми, пока соответствующий gate не закрыт.

## Какой eval используется

В репозитории намеренно сохранены два несовместимых уровня оценки:

- `grouped_text_v1` / `nested_grouped_v1` — историческая CV-5 для честного
  воспроизведения и сравнения экспериментов, из которых собрано решение 140;
- `semantic_family_v3` — текущий обязательный promotion gate для новых
  архитектурных выводов: связанные товарные семейства не пересекают folds.

Результаты разных протоколов нельзя складывать в одну таблицу. Текущий локальный
лидерборд новых кандидатов —
[`reports/semantic-v3-leaderboard.csv`](../reports/semantic-v3-leaderboard.csv).
Двухfoldовый screen не считается leaderboard-результатом.

## Почему встречаются разные CV-числа

| Значение | Протокол | Корректная интерпретация |
|---:|---|---|
| `0.9118425206` | nested grouped CV-5 | Трёхкомпонентный fusion до recurrence/product-memory слоя |
| `0.942878` | nested recurrence simulation | Историческая оптимистичная симуляция полного рецепта с train-donor memory |
| `0.8923976821` | Public leaderboard | Фактический результат неизменяемого архива решения 140 |

`0.942878` не является текущей оценкой переноса на новые семейства. Для новых
компонентов авторитетен только полный replay на `semantic_family_v3` с заранее
записанным gate.

## Важные подтверждённые выводы

- Две rsLoRA-ветки и robust base дают воспроизводимый nested fusion; точные
  команды и frozen OOF identities записаны в
  [`REPRODUCE.md`](../experiments/140_dual_lora_fusion/final/REPRODUCE.md).
- Тяжёлые 27B-модели дали полезный offline teacher signal, но не являются
  deployable-компонентом решения 140 из-за лимитов размера и времени.
- Отрицательные эксперименты сохраняются только тогда, когда есть терминальный
  измеренный результат и самостоятельный вывод. Незавершённые scaffolds удалены.
- Public используется как проверка заранее замороженного архива, а не как
  источник подбора порогов после отправки.
