# Эксперимент 603: разбор расхождений исходного маршрута и ансамбля четырёх инициализаций

Дата фиксации: 2026-08-22.

## Краткий вывод

Ансамбль четырёх инициализаций улучшает средний F1 двух категорий с `0.9136312475` до `0.9196036381` (`+0.0059723906`), но меняет только 54 из 11 118 ответов. Среди изменений 29 исправлений и 25 ухудшений. Поэтому общий прирост реален для этой OOF-таблицы, но хрупок: по F1 он положителен лишь на трёх из пяти разбиений, почти целиком обеспечен категорией «Легковоспламеняющиеся», а длинные тексты дают отрицательный баланс ошибок.

Самые содержательные сигналы для следующего цикла:

1. Для категории «БАД» явный признак того, что товар является добавкой, отделяет полезные изменения (`14/8`) от вредных (`4/10`). Это поддерживает проверку маршрутизатора, который требует проверяемое текстовое основание для спорного изменения.
2. Изменения `0 → 1` почти нейтральны по числу ошибок (`17/18`), а изменения `1 → 0` заметно надёжнее (`12/7`). Нужен асимметричный порог для двух направлений разногласия.
3. На текстах длиной от 1800 символов баланс `6/13`, тогда как на диапазоне 500–999 символов — `14/5`. Для длинных карточек следует проверить выбор релевантных фрагментов и согласование нескольких представлений текста.

Это разбор для выдвижения гипотез, а не основание принять новый вариант для отправки.

## Границы и воспроизводимость

- Использована только development-часть semantic-v3: 11 118 строк, пять групповых разбиений.
- Сопоставление ID, меток, категорий, номеров разбиений и семантических компонент проверено полностью до расчётов.
- Закрытая выборка не читалась и не использовалась.
- В отчёте нет названий и описаний товаров, ID строк, хешей семантических компонент, локальных путей, имён вычислительных заданий и примеров, по которым можно восстановить исходный текст.
- Текст применялся только локально для детерминированных индикаторов и длины. Наружу вынесены агрегаты.
- «Исправление» означает, что исходный маршрут ошибался, а ансамбль четырёх инициализаций дал верный ответ. «Ухудшение» — обратное изменение.

### Существенное ограничение валидации

Пороги эксперимента 603 подобраны по четырём другим разбиениям поверх уже готовых OOF-оценок. Это **leave-one-fold-out calibration over fixed OOF scores**, а не полностью вложенная мета-валидация (`fully_nested_meta_validation=false`). Модели-доноры, породившие OOF-оценки, могли обучаться на метках текущего внешнего разбиения. Следовательно, приведённые ниже срезы нельзя трактовать как несмещённую оценку обобщения маршрутизатора.

Кроме того, срезы выбраны после просмотра тех же 54 расхождений. Любое правило на их основе должно быть заранее зафиксировано и проверено на OOF, полученном с полным внешним переобучением, без подгонки по этим результатам.

## Следующие проверяемые гипотезы

Порядок ниже отражает ожидаемую информационную ценность, а не уже доказанный эффект.

### H1. Полностью вложенная перепроверка четырёх инициализаций

**Механизм.** Для каждого внешнего семантически сгруппированного разбиения заново обучить все четыре модели только на остальных внешних группах. Пороги и любые параметры маршрута подбирать исключительно на внутренних OOF-прогнозах обучающей части. Внешнее разбиение не должно участвовать ни в обучении доноров, ни в калибровке.

**Когорты.** Все данные; обязательные отчёты отдельно по категории, внешнему разбиению, размеру семьи и направлению изменения.

**Риск утечки.** Главный риск — повторное использование меток внешнего разбиения моделью-донором или порогом. Контроль: пересечение ID и семантических компонент между обучением и внешней оценкой равно нулю; происхождение каждого прогноза фиксируется.

**Быстрый экран.** Один заранее выбранный внешний fold как проверка конвейера, без решения GO/NO-GO по его метрике.

**Полный критерий принятия.** Пять внешних разбиений; средний прирост не меньше `+0.003`, выигрыш не менее чем на четырёх из пяти разбиений, ни одна категория не теряет больше `0.002`. Иначе наблюдаемый результат 603 считается недостаточно подтверждённым.

### H2. Асимметричный маршрутизатор разногласий

**Механизм.** Не менять согласованные ответы. Для `1 → 0` использовать обычный порог ансамбля; для `0 → 1` требовать больший запас вероятности и подтверждающий извлечённый фрагмент. Порог запаса заранее выбирается только во внутренней OOF-калибровке. Это проверяет наблюдение `12/7` против `17/18`, не запрещая положительные изменения полностью.

**Когорты.** Два направления изменения, обе категории; отдельно разбиение 2, где сосредоточены новые ложноположительные ответы.

**Риск семантического нарушения.** Слишком жёсткий положительный порог снижает полноту и положительный F1. Извлечённый фрагмент не может считаться доказательством, если он относится к аксессуару, отрицанию или предмету вне продаваемого комплекта.

**Быстрый экран.** Только development-OOF с полностью внешними прогнозами из H1; сравнить заранее фиксированные симметричный и асимметричный варианты.

**Полный критерий принятия.** Сохранить не менее 80% исправлений `0 → 1`, сократить их ухудшения не менее чем на 30%, получить общий прирост не меньше `+0.003` и выиграть не менее четырёх внешних разбиений.

### H3. Проверяемое основание для изменений в категории «БАД»

**Механизм.** Для спорного изменения ансамбля извлекать точный фрагмент, который прямо указывает на тип продаваемого товара, состав или назначение. Если есть только косвенное упоминание, отрицание либо описание совместимого товара, сохранять исходный ответ. Начальный детерминированный словарь служит лишь нулевой линией; основной вариант должен учиться на development-train и выдавать точные смещения фрагмента.

**Когорты.** БАД с прямым индикатором (`14/8`) и без него (`4/10`); пересечения с отрицанием и областью действия; уникальные и повторяющиеся семьи.

**Риск утечки и смысловой ошибки.** Словарь выбран после анализа ошибок и не может оцениваться на тех же OOF как готовое решение. Упоминание БАД в сравнении, предупреждении или комплекте не доказывает, что продаётся БАД. Фрагменты строятся без метки текущего внешнего fold; ручная проверка проводится на заранее отложенной подвыборке.

**Быстрый экран.** Проверить только качество извлечения: точное попадание фрагмента, покрытие разногласий и долю конфликтующих фрагментов, без оптимизации порога по текущим 54 строкам.

**Полный критерий принятия.** На полностью вложенных OOF сократить ухудшения в БАД без прямого основания минимум на 50%, сохранить минимум 85% исправлений с прямым основанием, не ухудшить F1 категории БАД и получить не менее 80% релевантных объяснений на слепой ручной проверке.

### H4. Многопредставленное обучение для длинных карточек

**Механизм.** Для строк ≥1800 символов обучать согласование трёх представлений: название и начало описания, окна вокруг найденных предметов/веществ и полный доступный контекст. На выводе изменение исходного ответа допускается только при согласии полного представления с доказательным окном; иначе используется исходный маршрут.

**Когорты.** Заранее фиксированные длины `<500`, `500–999`, `1000–1799`, `≥1800`; отдельно две категории и наличие индикаторов области действия.

**Риск семантического нарушения.** Окна могут вырезать отрицание или связать вещество не с продаваемым товаром. Все окна должны сохранять исходные точные смещения и включать предложение с отрицанием/комплектностью. Нельзя выбирать окна по истинной метке.

**Быстрый экран.** CPU-проверка покрытия извлечённых окон и один короткий внешний-fold запуск с замороженными правилами формирования представлений.

**Полный критерий принятия.** На полностью вложенных пяти fold для ≥1800 исправлений не меньше, чем ухудшений; сохранить минимум 80% из 14 исправлений диапазона 500–999 относительно воспроизведённого базового анализа; общий прирост не меньше `+0.003`, без потери категории свыше `0.002`.

## Решение по результатам разбора

Ансамбль четырёх инициализаций остаётся перспективным объектом исследования, но не считается подтверждённым кандидатом только по эксперименту 603. Сначала требуется H1. Параллельно можно готовить label-free извлечение фрагментов для H2–H4, поскольку оно не зависит от результата переобучения и одновременно улучшает проверяемость объяснений.
