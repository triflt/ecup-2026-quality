# План до финального решения

Цель репозитория — не сохранить максимальное число экспериментов, а довести
**финальную систему 140 + 714** до состояния, в котором жюри может понять её, воспроизвести
кодовый путь и проверить ровно тот архив, который получил результат на Public.

- Зафиксированный Public Macro F1: **0.8923976821**.
- Историческая оценка вложенного слияния на CV-5: **0.9118425206**.

- Новые архитектурные выводы принимаются только после полного прогона
  `semantic_family_v3`; исторические результаты `grouped_text_v1` остаются для
  сопоставимости с решением 140.
- Технический пакет собран в
  [`experiments/140_dual_lora_fusion/final/`](../experiments/140_dual_lora_fusion/final/).
- Frozen Exp714 ZIP: 55 770 475 байт; 600/600 schema valid, 0 изменений verdict;

## Обязательно закрыть до финальной публикации

1. **Опубликовать веса и артефакты.** Для двух LoRA-адаптеров и обученных
   классификаторов записать публичные неизменяемые URI, размер и SHA-256 в
   `artifact-contract.json`.
2. **Закрыть точное воспроизведение.** Опубликовать три зафиксированных
   OOF-массива либо ссылки на
   них с уже записанными SHA-256 и схемой колонок.
3. **Проверить чистую сборку.** Из нового клона воспроизвести frozen ZIP по
   опубликованным весам и подтвердить SHA.
4. **Подтвердить runtime.** Запустить выбранный ZIP на Public без сети и записать
   фактическое время; добавить размер Docker-образа.
5. **Проверить объяснения.** Объяснение должно ссылаться на конкретные признаки
   карточки, не менять вердикт классификатора и пройти слепую ручную проверку.
6. **Зафиксировать Public нового архива.** Одна отправка заранее выбранного ZIP,
   без тюнинга по результату.

## Правило следующих экспериментов

Новая модель или компонент продолжается, только если заранее записаны базовый
результат, протокол, критерии принятия и ожидаемая роль в отправляемом решении.
Быстрая проверка на одном или двух фолдах может только отклонить гипотезу. Для
принятия нужен полный `semantic_family_v3`: выигрыш большинства фолдов,
положительная общая дельта, отсутствие просадки редкого класса и прохождение
ограничений по времени и размеру.

Public используется как редкий независимый сигнал переноса. Отправляется один
заранее выбранный неизменяемый кандидат с записанным SHA; Public нельзя превращать
в цикл подбора порогов между множеством почти одинаковых архивов.

## Сохранённые отрицательные выводы

В репозитории остаются измеренные отрицательные эксперименты, которые запрещают
повторять уже проверенные ветки: прямые промпты, жёсткие правила поверх модели,
агрессивную фильтрацию, multi-image LoRA, Gemma в основном слиянии, логистический
стекер, OCR поверх сильного ансамбля, смеси адаптеров без устойчивого переноса
между фолдами и варианты дистилляции или ранжирования, не прошедшие
зафиксированные критерии.
