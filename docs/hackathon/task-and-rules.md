# Задача и правила соревнования

Публичная техническая выжимка требований, которым должен соответствовать репозиторий и финальное решение. Закрытые обсуждения, служебная переписка и внутренние ссылки здесь не хранятся.

## Постановка задачи

Для каждой карточки товара требуется проверить, подтверждается ли заявленная категория, решить, должна ли карточка получить запрет, и сформировать краткое объяснение. Категория заранее известна: `БАД` или `Легковоспламеняющиеся`.

В обучающих данных:

- `label=1` — категория подтверждается, вердикт `не бан`;
- `label=0` — категория не подтверждается, вердикт `бан`.

Решение запускается без доступа к интернету. Путь к тестовым данным передаётся через `--test_data_path` (`-i`), путь к итоговому файлу — через `--output-path` (`-o`). Итоговый CSV содержит столбцы `id` и `result`.

```text
<комментарий>конкретное объяснение длиной от 50 до 300 символов<вердикт>бан
```

Допустимы только вердикты `бан` и `не бан`. Закрывающие теги не используются.

## Проверка и метрика

Проверка проходит последовательно:

1. формат и запуск решения;
2. Public leaderboard;
3. Private leaderboard;
4. проверка соблюдения правил и качества объяснений финалистов.

Основная числовая метрика — среднее F1 по двум категориям (`Macro Averaged F1`). Объяснение — самостоятельная обязательная часть результата: оно должно называть конкретный признак карточки, согласовываться с вердиктом и опираться на название, описание или изображение.

## Ограничения запуска

- 20 CPU;
- 100 GB RAM;
- NVIDIA H100 80 GB;
- до 3 минут на техническую проверку;
- до 20 минут на Public;
- до 40 минут на Private;
- архив решения не более 5 GB;
- сжатый Docker-образ не более 15 GB;
- не более пяти отправок в сутки;
- команда не более пяти человек;
- для финального зачёта выбираются не более двух решений.

Финальный пакет должен оставлять запас по времени и размеру, а не целиться ровно в лимит.

## Модели и воспроизводимость

Разрешены открытые модели с подходящей лицензией и подтверждаемым происхождением. Небольшие обученные адаптеры, включая LoRA, допустимы. Репозиторий должен содержать:

- код обучения и инференса;
- зафиксированные конфигурации;
- описание данных и валидации;
- команды воспроизведения;
- контрольные суммы финальных артефактов;
- результаты runtime/schema проверки.

Raw data, закрытые модели, приватные execution-конфигурации и веса в Git не публикуются.

## Данные и синтетические примеры

Внешние наборы данных, включая данные других соревнований, запрещены. Синтетические примеры и автоматическая разметка допустимы, если:

- использована открытая модель с разрешающей лицензией;
- размер модели-учителя не превышает 400 миллиардов параметров;
- сохранены версия модели, prompt/процедура и код генерации;
- процедуру можно воспроизвести хотя бы на нескольких тысячах примеров;
- закрытые коммерческие модели не используются для создания скрытой разметки или обучающих объяснений.

## Проверка соответствия репозитория

| Правило | Реализация в репозитории | Состояние |
|---|---|---|
| Официальный `-i/-o` CLI | `submission/run.py` финального experiment package | Требует заполнить README-плейсхолдер |
| CSV `id,result` и формат тегов | formatter + schema tests | Реализовано в submission candidates |
| Offline inference | сетевые зависимости запрещены в runtime | Проверяется smoke-тестом |
| Macro F1 по категориям | frozen CV-5 + category metrics | Реализовано |
| Конкретные объяснения | отдельный explanation quality gate | Ещё не отмечен принятым в champion report |
| Лимит времени | масштабный runtime smoke | Требует финального replay |
| Лимит размера | immutable archive manifest | Требует финального artifact |
| Воспроизводимость | experiment packages, registries, checksums | Реализовано; финальный handoff надо заполнить |
| Запрет внешних данных | dataset registry и audit | Реализовано |
| Synthetic provenance | generator/model/license/methodology | Обязательно для выбранной synth-ветки |

Главные незакрытые пункты перед финальной публикацией: выбрать точный лучший package, заполнить его команды в корневом README, подтвердить explanation gate, переснять runtime и размер неизменяемого архива.
