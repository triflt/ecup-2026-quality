# Учебный разбор данных

Основной файл: `ecup_quality_data_report_ru.ipynb`.

Notebook объясняет постановку задачи, устройство двух лучших решений, распределения меток, длины текстов, повторяющиеся товарные семейства, противоречивые метки и роль изображений. Все пояснения написаны по-русски.

Для разбора ошибок текущего локального лидера используйте отдельный набор таблиц в `experiments/230_qwen35_second_seed/analysis/`. Начните с `cohort_metrics.csv`, затем откройте `changed_decisions.csv` и `remaining_errors.csv`. Там сохранены вероятности двух Qwen3.5, размер товарного семейства и полный текст карточки.

## Локальные данные

Исходный CSV не публикуется. По умолчанию notebook ищет его в `../../research/data.csv`. Другой путь можно передать через переменную окружения `ECUP_DATA_CSV`.

В `assets/images/` локально лежат только 11 демонстрационных изображений трёх товаров. Они выбраны из проверенной распаковки предоставленного организаторами S3-архива:

- `4424` — БАД, `label=1`: явный пример подтверждённой категории;
- `5192` — БАД, `label=0`: добавка, похожая на БАД, но без достаточной маркировки;
- `4040` — легковоспламеняющиеся, `label=0`: газовая горелка без топлива в комплекте.

Изображения и исходные данные исключены из Git. В репозитории сохраняются notebook, код анализа и список выбранных идентификаторов.

## Запуск

```bash
uv run --with jupyter --with matplotlib --with seaborn \
  jupyter lab notebooks/data_overview_ru/ecup_quality_data_report_ru.ipynb
```

Для полной проверки количества изображений можно передать корень всей распакованной папки:

```bash
ECUP_IMAGES_DIR=/path/to/images \
  uv run --with jupyter --with matplotlib --with seaborn jupyter lab
```
