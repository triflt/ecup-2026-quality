# Explanation synth v5

Этот набор содержит 11 400 коротких объяснений для обучающей выборки
E-CUP 2026 Quality. Каждая строка привязана к исходной карточке по `id` и к её
исходному `label`.

Файл `explanations.jsonl` имеет простую схему:

```json
{"id":"0","label":1,"target":"Продаётся биологически активная добавка ..."}
```

- `id` — идентификатор строки в `competition_train_v1`;
- `label` — исходная метка соревнования, а не новый прогноз teacher;
- `target` — конкретный комментарий длиной 50–300 символов.

## Как получены комментарии

Teacher: `Qwen/Qwen3.5-397B-A17B-FP8`, revision
`ea5b4f81096f3901c91dea97f81324302495781d`.

Teacher получал категорию, исходную train-метку, название, описание и всю
галерею карточки. Он должен был вернуть один JSON с `label`, закрытым `reason`,
одним проверяемым `evidence` и коротким `explanation`. Декодирование было
детерминированным: `temperature=0`, `top_p=1`, `max_tokens=384`, thinking
выключен.

Полный prompt, parser и validator находятся в
[`experiments/712_qwen35_397b_evidence_teacher/prompt.py`](../../experiments/712_qwen35_397b_evidence_teacher/prompt.py),
а orchestration полного прохода — в
[`generate_all.py`](../../experiments/712_qwen35_397b_evidence_teacher/generate_all.py).

После генерации были исключены `not_enough_evidence`, невалидные JSON,
недоступные evidence-ссылки и объяснения, для которых необходимы изображения
после `image0`. Для student SFT оставлены только комментарии, поддерживаемые
названием, описанием или первым изображением. Исходные изображения в этот
dataset не копировались и не перекодировались.

## Назначение

Основной режим обучения — full-data SFT объясняющей Qwen3.5-4B:

```text
input:  штатные данные карточки + готовый label/verdict
target: только target из explanations.jsonl
```

Эта модель генерирует комментарий к уже готовому решению классификатора и не
должна менять score, fusion или verdict ансамбля.

## Ограничения

Покрытие неравномерно: минимальное покрытие у `БАД / label=0` — 67.40%.
Автоматический audit проверил структуру, доступность evidence и отсутствие
усечения target, но не заменяет ручную семантическую проверку. В корпусе могут
оставаться стилистически модельные формулировки; это зафиксированная версия
teacher outputs, а не ручная разметка.

Контрольные суммы и полная статистика приведены в `manifest.json`.
