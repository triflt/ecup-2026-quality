# Версии данных

Raw competition data не хранятся в Git. Каждый experiment package обязан ссылаться на неизменяемый `version` из `registry.toml`; локальный путь передаётся через CLI и не является идентификатором dataset.

Новая выгрузка, исправление разметки или изменение состава строк получает новую версию. Старую запись и её checksum не редактируют: это необходимо, чтобы leaderboard и CV результаты оставались сравнимыми.
