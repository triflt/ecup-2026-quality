# Данные и валидация

## ⭐ Основная проверка: CV-5

Каноническая точка входа в пятифолдовую валидацию — [`cv5/`](cv5/). Там
зафиксированы фолды, скрипт их построения, методология вложенной CV и связь
исторической оценки с более строгой проверкой товарных семейств.

## Версии данных

Исходные данные соревнования не хранятся в Git. Каждый эксперимент ссылается
на неизменяемую версию из `registry.toml`; локальный путь передаётся через CLI
и не служит идентификатором данных.

Новая выгрузка, исправление разметки или изменение состава строк получает новую
версию. Старую запись и её контрольную сумму не редактируют, чтобы результаты
CV и локального лидерборда оставались сравнимыми.
